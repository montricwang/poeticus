# `INTERTEXT` 论证方法聚类：第一轮实验（2026-10-21）

关联 Issue #372。本实验用于**挑选值得精读的论证样本**，不是自动确定文学批评分类法。

## 数据与可复现性

- 数据：私有 `critic_methods_reviewed_v2_1505.jsonl`，包含 1505 篇研究卡。
- 只取 `methods[].code == INTERTEXT` 且 `argument_path` 非空：949 条论证路径。
- 向模型输入**仅含 `argument_path`**，评论者、词人、篇名、引文不进入向量。
- 固定种子 `20261021` 抽样 120 条，使用本地 `Qwen3-Embedding-0.6B`，余弦距离；`KMeans(k=8)` 强制粗分组。
- 原始书籍、论证路径、分组成员与审读笔记全部保存在仓库外的私有目录；此处只记录聚合指标和方法判断。

从仓库目录运行（路径请换成自己的本地路径）：

```bash
python -m scripts.research.cluster_critic_methods \
  --input ../poeticus-data/critic-methods/results/critic_methods_reviewed_v2_1505.jsonl \
  --model-dir ../poeticus-data/models/Qwen3-Embedding-0.6B-7c0e29cfcdf2 \
  --output-dir ../poeticus-data/critic-methods/results/intertext_pilot_2026-10-21 \
  --limit 120 --clusters 8
python -m unittest tests.test_cluster_critic_methods -v
```

输出目录必须在公开仓库外，而且脚本拒绝覆盖已有结果。复跑请换一个输出目录。

## 第一轮观察

| 项目 | 结果 |
| --- | --- |
| 可用路径 | 949 |
| 样本 | 120 |
| 强制组数 | 8 |
| 各组样本数（降序） | 23、22、16、16、12、11、11、9 |
| 余弦轮廓系数 | **0.0169** |
| 精读原赏析 | 10 篇，目的性选样，不能估计总体占比 |

轮廓系数几乎为零：目前**没有证据**证明八组是稳定的文学批评子方法。人工对照发现：

1. 部分相近条目是按“梅花、梳妆”等题材与意象靠近，并非采取同一论证步骤。
2. 有些相近条目碰到了可复用动作：核对前文本中的语句或叙事顺序，观察新作品如何省略、移位、重组、反转，并据此解释审美效果。
3. 一个大标签可同时混合“典故释义”“平行比较”“追索来源”“同作者互证”等不同目的；单条简短的 `argument_path` 也可能同时包含多步动作。
4. 精读的十篇覆盖了同簇近邻和跨簇对比：既出现了“逐段核对前文本并分析新作重组”的操作，也出现了“同作者同时期作品互证”和“相似意象但非直接借用”等不同证据关系。仅凭向量近邻，无法自动区分这些关系。
5. 某些赏析借类比推出“别有寄托”或人物心理，评论者自己也保留了猜测空间；未来手册需要附上**推断边界**，避免把联想当作确证。

## 决定：暂停扩大规模，改从动作入手

下一轮先从**不同初步分组与离群条目**中挑选 30—50 条，回看评论原文，暂拟可多选的动作标签：

- **定源**：有何证据认为与哪一篇旧作有关？区分直接化用和一般语汇传统。
- **释典**：原故事/原文本提供什么语义，哪些是评论者补加的推测？
- **比异**：指出字词、叙述、对象或语气相同和不同之处。
- **析变**：识别省略、换位、组合、反转及其表达效果。
- **互证**：用同作者其他作品、历史材料或多个平行文本支持/限制解释。

每条尝试表示成“引用材料 → 评论者做的操作 → 得出的判断”，允许多动作、反例与不确定项。只有这些人工标签能让不同的人重复识别，并能帮助 Poeticus 写出**具体可执行的分析步骤**，再考虑对子类聚类、自动分类或 Agent 路由。

这一轮**不训练分类器、不扩大到 949 条、不把机器簇当成知识树**。分类与手册应由核验过的动作案例驱动。
