## 校核及后续评测边界

1. **现在只是候选题**：作品正文、术语和争议预设未逐条核验；先核候选诗文的准确性、底本、题目是否真实可回答，再标记正式状态。
2. **题库与 Gold 分离**：review_focus 是给人审题时看的评估关注点，不是标准答案、API 路由规则或可以喂给被测 Agent 的 Prompt。
3. **真实评测不强制工具**：比较答案的准确性、适切性、证据来源、不确定性表达及工具滥用；按真实 Agent Trace 判断究竟调用了什么。
4. **对照实验另行实施**：现有 Agent 与启用 CNKGraph 研究工具的 Agent统一对照；复用 #344 的词学 Document RAG 金标准时，仍需分别报告纯检索指标与综合回答质量。
5. **保护题集独立性**：不能在开发过程中把预留组当反复改 Prompt 的训练样本。正式 held-out 必须经人工审核与实验隔离后再封存。
