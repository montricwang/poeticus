# Skill A/B/C 对照实验（尚未执行）

目标：检验来自 225 条互文研究记录的操作方法，能否在未参与研究的新作品上帮助 Poeticus 做出更可靠、更具体、同时更自然的文学解释。

## 实验组

- D：现有 Agent，不加载互文 Skill（基线）。
- A：仅加载简洁版。
- B：仅加载标准版。
- C：仅加载详细版；参考文件只有在需要时才读取，并记录是否读取。

三个版本名称与触发 description 相同，一次只加载一个。首次可用相同基础模型、相同工具池、温度、token 上限、检索材料和问题顺序；题目应打乱，不让上轮答案进入下一轮上下文。对“是否选择 Skill”与“Skill 被使用后是否有帮助”分别评价，避免工具调用频率掩盖实际效果。

## 题目

首轮推荐约 20–30 题：需要确定化用对象的、同题/赠答比较的、典故与共享意象难区分的、同作者作品可能互证的、以及实际不需要互文的负例。优先选没有进入 1505 篇研究库的作品；以作品标识排除研究集，必要时同时排除同一问题的换写。

另建熟悉的回归题集（例如已有的“阴阴夏木啭黄鹂”出处争议），只检查旧错误有无重现，不计入未见作品主指标。

每题固定：id、作品/词牌、问题、必要原典索引、是否应触发互文、可核查的来源争点、评价备注。不能只让被测模型自己给答案打分。

## 评价尺度

每项 0–2 分，尽量由不知实验组别的评审依据文本与来源评定：

1. **事实与引用**：出处、原句、人物与关系是否准确；捏造关键来源计 0。
2. **比较有效性**：是否指出具体的改写、视角或语义差异；泛泛称“相似”计低分。
3. **推断校准**：区分事实、解释和猜测；有争议时能否保持证据等级。
4. **问题适配**：确实回答提问；不相关互文堆砌或过度套流程扣分。
5. **表达自然度**：没有机械分段与术语堆叠，解释易懂但不空泛。

另外记录：工具实际调用、引用覆盖、推理耗时、token/费用、技能是否触发、额外参考文件是否加载，以及个案失败原因。

## 停止与晋升

- 不能因为 C 更长就判为更好；不能把得分变化归因于 Skill，除非对照中其他条件相同。
- 基于少量题目，只能筛选候选版本；要上线还须扩大题量与复测稳定性。
- 若 A/B/C 都不优于基线，先保留研究资料和失败案例，暂停生产接入。
- 只有发现稳定收益，才在 #311 下另建 Agent Skill 加载与路由的子 Issue；当前不改线上 Agent。
