# 诗词互文分析：详细版（C）

目标不是搜罗尽可能多的典故，而是借另一个可靠文本解释当前作品中一个明确的问题。互文是可选择的分析路径，不预设任何词都必须有来源、都必须表达作者生平。

## 触发与退出

- 适用：用户明确问典故、词句来源、化用、唱和、同题比较、传统意象；或单篇细读产生了需要外部文本才能检验的假说。
- 不适用：没有可靠参照对象的普通赏析、只需释词的提问、凑巧出现常见意象的作品。
- 在检索不到可信参照、文本联系过弱或比较无法解释本篇时，结束互文路线，直接完成原问题，不为了使用 Skill 生造连接。

## 选择分析路径

优先确定证据与问题类型，再选路径；可以组合，不需顺序覆盖。

1. **赠答、唱和、同调**：并列两篇文本，定位响应词语、角色位置、叙述起点、结构转折和回应方式；不要从传奇本事循环证明真实史事。
2. **化用与翻新**：先指出确有对应的字句、意象或结构，再问后作保留、删改、替换、反转了什么，解释这项改动在本篇的效果；共同语汇不自动证明直接取法。
3. **典故、语义、意象传统**：核对可追索的早期用例和语境，检视中间传播的可能；区分专指某篇的引用、借用共享母题、后人附会的意义。
4. **同作者跨篇互证**：把重复词语、人物称呼、场景与地点作平行核对，可能辅助解释写法；诗中情境本身不是作者传记材料，同类情节不能定为同一事件。
5. **传统与个体偏离**：用有依据的题材／体式惯例作参照，辨认本篇从常例中改变的字词、观察位置、情绪方向和写法。审美评价须展示比较依据，不把它包装成机械测量。

各路径的具体问题与来源记录索引，见 references/methods.md。

## 证据与结论的层级

- **可核验的文本事实**：版本、作者归属（如有争议需说明）、原句、词序/小序、明确的对应。
- **有根据的解释**：两者如何相似、哪里不同、这种差异为何增强或改变本篇意思；用词准确表示判断程度。
- **仍待证实的假说**：谁影响了谁、作者写给谁、某意象必指现实某事、作者的政治用意。仅凭相似关系不能上升为定论。

一个可用的工作循环是：提出疑问 → 寻找可比文本 → 核对具体对应 → 解释变化 → 寻找最强替代解释或反证 → 回答用户。只有问题需要时才重复检索或增加案例。

## 来源纪律

- 先查作品正文和可靠出处，再参考后代赏析。后人评语不等于作者自述。
- 可能存在多位前人、同一传统或异文时，不能只选择最熟悉的作者作为唯一来源。
- 明确引用真实调用过的资料；检索未成功就承认没有核实，不虚构原句、书名、页码和工具历史。
- 不强制固定五段式回答；最后用自然、具体、适合提问者的语言表达，避免以流程名代替审美判断。

遇到来源争议、同作者生平推断、晚出文献或标签误分时，按需阅读 references/pitfalls.md。需要参考怎样把方法从原先研究卡迁移到新词时，阅读 references/examples.md；这些案例用于说明分析动作，不能当成未见作品测试集。
