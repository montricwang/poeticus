# 从研究卡归纳方法：简化案例

以下只记录可迁移的研究动作与局限，未复制《唐宋词鉴赏辞典》的赏析段落。索引指向用户私人研究档案的 record_id，不是公开可检索引文。案例来自构建 Skill 的数据，不可混入性能评测的未见作品集。

## 1. 唱和中同一个字的角色变化

- 私人记录：0003:m2，韩翃《章台柳》与柳氏答词。
- 动作：比较赠与答如何响应同一词语，识别意象在两个人话语中的身份差异。
- 可迁移做法：问“这个字回应了什么、谁对谁说、回应改变了怎样的情感位置”，不要仅说“两首互文”。
- 局限：有关乱离的传奇叙述未必能独立证明真实事件。

## 2. 逐句化用与后作改造

- 私人记录：0010:m2，释德诚《拨棹歌》与黄庭坚《诉衷情》。
- 动作：把参照作品逐句对齐，区分留存和改写。
- 可迁移做法：即使批评家称“夺胎换骨”，分析仍须展示改换的地方，并解释它对后作意味着什么。
- 局限：单凭评语还不能把影响关系当作已经独立证实的文学史事实。

## 3. 原唱、和词之间的视角转移

- 私人记录：0011:m0，白居易与刘禹锡相关《忆江南》作品。
- 动作：对照原唱和和作的叙述方向、所写对象与焦点变化。
- 可迁移做法：比较“写谁／为谁写／从哪一面写”，再谈情感重心；不必每次都附加政治寓意。
- 局限：由春逝推断个人政治际遇，需要额外证据。

## 4. 同作者跨篇互证

- 私人记录：0021:m3、0025:m0。
- 动作：并读同一作者的数篇作品，核对反复出现的场景、地点和人物称谓。
- 可迁移做法：让其他作品为某种阅读提供旁证或反例，不把共同场景直接写成同一人或同一件生平事件。
- 局限：诗歌惯例可能造成貌似连续的故事，传记断言需独立史料。

## 5. 意象历史而非单一出处

- 私人记录：0029:m2，跨《楚辞》、唐诗与戏曲考察草、柳、马的送别联想。
- 动作：观察多时代文本怎样积累某组意象的联想。
- 可迁移做法：从历史用例描述传统，不因“常用于送别”就声称当前作者确有一次具体送别。
- 局限：母题传播的历史路径可能并不连续，不能凭少数例子倒推出传承谱系。
