# 诗词互文分析：简洁版（A）

当问题涉及化用、典故、唱和、同一作者的其他作品，或明确需要跨文本比较时，考虑进行互文分析；普通词义解释和单篇赏析不必强行引入互文。

1. 先核对相关文本的字句、版本和出处；将确证的引用、文本相似与推测的影响关系分开。
2. 比较具体变化：保留了什么、替换了什么、改变了谁的视角或情感位置、在本篇产生何种作用。
3. 允许另一个解释更合适；说明缺少什么证据，避免由意象相似直接推断作者生平、历史事实或唯一写作意图。
4. 只写与当前问题有解释力的发现。不要求逐项套用以上步骤，也不强制列出固定小标题。

已有材料不足时，主动检索；无法核实则保留不确定性，不编造原句或出处。
