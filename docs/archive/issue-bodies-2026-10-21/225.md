## 背景

Poeticus 当前在 `frontend/src/lib/poem-layout.ts` 中根据 `，,。.!！?？` 分行。#214 的实验性阶梯缩进又根据这些标点增加或重置缩进层级。然而导入的《历代名家词集精华录》采用现代编辑标点，**不能直接把这些标点视为词体格律结构的可靠替代**。

**需要核查的具体例子：**

- 周邦彦《兰陵王·柳》：`凄恻，恨堆积，渐别浦萦回，津堠岑寂，斜阳冉冉春无极。`，与将 `恨堆积` 后标成感叹号的读法，以及改用句号的其他版本相比，单凭标点会产生不同的阶梯缩进。
- 辛弃疾《兰陵王》：用户发现以冒号和引号引出的编者引文。决定这些符号是否应进入阅读标点前，先核对原书的准确文字和其他版本。
- 李煜《谢新恩·樱桃落尽春将困》：文本残缺，且是否能套用标准公开词谱尚不确定。词谱**无法匹配**应视为待调查，不能自动判定文本格式错误。关联 #221。

## 范围：先调查，不改写语料

1. **盘点现有标点，区分来源并汇总全库。** 逐字统计 `，。！？；：、`、引号、括号及编辑标记，记录受影响的作品数量，以及异常连用或过长标点序列。生成只读 CSV／JSONL 候选清单，以稳定的来源记录 ID 标识，附简短片段与原书位置；保留原始字符串。
2. **先验证外部能力，再决定是否围绕它开发。** 调查 CNKGraph 词牌／格律服务是否真实提供可用且有文档的**批量调用或 API**，以及速率限制和非商业许可。公开 API Explorer 不足以证明某个格律端点真实可用。只有必要时才比较搜韵等现有词谱／格律校验器（如《钦定词谱》《唐宋词格律》）；未经许可核验不抓取。
3. **先做少量代表性实验，不直接批处理 3491 首。** 覆盖常见规则词牌、多种变体、异常标点、《兰陵王》长调、引文和残缺的《谢新恩》；记录匹配覆盖率、具体词谱依据、歧义／失败样本，以及可能的格律边界位置。如果提供方要求无标点文本，要确认匹配输入没有夹带标点。
4. **区分格律边界与界面显示标点。** 候选标点方案可参考唐圭璋《全宋词》的韵位 `。`、句界 `，`、读 `、`，但它只是**产品编辑选择**，不能据此判定现代问号、感叹号或引号全部错误。优先生成有依据且可人工审阅的阅读排版标注或修订提案，不凭标点猜测。如果无法匹配词谱或有多个合理变体，保留原文并标记 `needs_review`。
5. **先出报告，不自动修改数据。** 对每首作品输出原始标点、建议断句／韵位、匹配的词牌／词谱形式及置信度／证据、差异和原因代码（词谱歧义／无匹配词谱／作品残缺／引文／文本存疑）。不得自动更新 `body_segments`、删除文学引文、更改 `text_version` 或执行数据库迁移。任何获准的阅读文字修订都须遵守 #36 的语料版本政策。

## 2026-10-12｜CNKGraph 格律分析的三条实现路线（用户讨论补充）

**用户提出的具体 trade-off**：优先直接复用 [CNKGraph 数字化词律分析网页](https://cnkgraph.com/Tool/TuneAnalyze) **已有的匹配结果**；若不便以许可允许的接口取得网页分析结果，查看 [CNKGraph Swagger](https://open.cnkgraph.com/swagger) 是否有可调用的词律/词谱匹配端点；若只能拿到某词牌的标准谱式/变体信息，也可把谱式+当前词正文交给 LLM 做逐句形式分析，作为低门槛降级方案。



**严格区分**：A. 已有网页工具直接解析正文并返回韵位/平仄/词式；B. API 返回正式匹配结果；C. API 只返回『词牌应是什么格式』，需要我们再做逐字对位，LLM 用作解释/辅助判断。A/B 更确定、响应可能更快；C 更灵活但需要处理历史读音、多音字、入声、拗救、异体与变格，**LLM 逐字判平仄不能当确定性校勘器**。优先官方页面允许调用的真实功能或稳定官方端点，不擅自绕过登录和反爬/授权。



**最小对照**：对一首常见词牌、一首长调多变体和一首残词分别保存网页/端点的可核响应（如果可合法调用），与 C 方案并排检查：谱式与作品分句是否对齐、每字平仄是否能追到音韵依据、遇到不合律是否错误归责原文；若无可用接口，明确记限制，不因此修改语料或展示标点。#225 原有评测和不自动改写约束继续有效。
