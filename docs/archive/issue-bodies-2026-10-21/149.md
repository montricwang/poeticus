## 背景

随着 Commentary Corpus、Text Retrieval 和 Critic Persona 演进，Poeticus 未来可能需要稳定回答：

- 谁评论过谁？
- 某个词学概念在哪些文献出现？
- 哪些批评家共同讨论过同一词人 / 作品？
- 一个概念从宋代到清代、近代经过哪些重新解释？
- 某位现代学者回应了哪些旧说？

这些问题不只是“找相关文本”，而是需要稳定地沿实体关系查询。

本 Issue 记录知识图谱的初步选型，不代表现在立即引入 Neo4j / RDF。

## 核心判断

> **RAG 主要找文本；知识图谱主要找关系。**

关系型数据库也能保存图状信息；真正需要 Graph 的信号，是多跳关系本身逐渐成为主要查询对象。

Poeticus 当前尚未被业务逼到必须采用专门图数据库，第一版可优先利用现有 PostgreSQL 的关系表 / edge table。

## 知识图谱适合显性化的内容

优先保存相对稳定、低解释性的关系：

- Person AUTHORED Document / Work
- Critic COMMENTED_ON Person / Work
- Document QUOTED Document / Work
- Document MENTIONED Concept / Person / Work
- Critic / Document ASSOCIATED_WITH Concept
- Work BELONGS_TO Collection
- Person / Work 的别名与同一实体关系

图谱作为 Library / Notebook 之间的“关系骨架”，不承担全部文学理解。

## 谓词设计原则：优先低承诺关系

例如：

~~~text
张炎 --评价--> 姜夔
~~~

通常比：

~~~text
张炎 --推崇--> 姜夔
~~~

更稳定。

同样：

- 评价 / 提及 / 引用 / 讨论：低承诺，可直接由文献证据支持；
- 推崇 / 贬低 / 继承 / 反对 / 影响：解释性更强，容易涉及范围、语气、强度和后世概括。

因此：

> **图谱优先保存“发生过什么关系”；评论系统再判断“这个关系意味着什么”。**

高解释性判断更适合作为带 provenance 的 claim / edge properties，而不是直接冻结成强谓词。

## 每条关系必须保留 provenance

建议至少能够追溯：

~~~text
source_document
source_location / passage
extractor
confidence
scope
review_status
~~~

例如不是只存：

~~~text
王国维 --负面评价--> 吴文英
~~~

而是保留：

~~~text
王国维 --评价--> 吴文英
source: 《人间词话》某则
claim / tendency: ...
scope: 具体词风 / 作品范围
~~~

避免图画得干净以后给人“事实也很干净”的错觉。

## 实体消歧与归一

需要特别关注：

- 白石 / 姜夔 / 姜白石 / 白石道人；
- 东坡 / 苏轼 / 东坡乐府等不同对象；
- 抽象概念如“清空 / 清空骚雅 / 清空之气”是否应合并，不能仅依字面自动处理。

人名、作品名可较多自动化；抽象词学概念需要更保守。

## PostgreSQL 与专用图数据库的比较

第一阶段候选：

~~~text
entities
relations
claims
sources
aliases
~~~

利用 PostgreSQL 完成小型图模型，并通过普通 SQL 验证真实产品查询。

出现以下信号时，再评估 Neo4j / 专门 Graph Store：

- 多跳查询频繁；
- 路径查询成为核心能力；
- 同一实体连接数量显著增长；
- SQL recursive CTE / join 开始成为主要工程负担；
- 需要图算法 / community / path ranking 等能力。

## 自动构图

LLM 可用于：

- 实体候选抽取；
- 关系候选抽取；
- 初步 Schema suggestion；
- alias / entity resolution 候选；
- relation review。

但采用“自动生成 + 人工 / 规则治理”而不是无监督写入 Canonical Graph。

## 非目标

- 不把全部人文学理解压成三元组；
- 不要求“清空”等概念存在唯一稳定定义；
- 不预先引入复杂 ontology；
- 不因为名为 Knowledge Graph 就立即迁移到 Neo4j；
- 不让自动抽取结果绕过 provenance 与 review。
