## 目标
用独立的本地 Web 控制台统一管理 Poeticus 开发机服务，免去手动开启多个 Windows Terminal 标签。用户可独立启停 Frontend、Backend、LangGraph、Retrieval、Reranker、Cloudflare Tunnel，以及已有 Local MCP Manager。

## 首版范围
- [x] Windows 后台管理器与本地网页，固定监听 127.0.0.1
- [x] 服务状态、单项及批量启停、重启；避免重复启动或停止外部进程
- [x] stdout/stderr 写本地持久日志，SSE 推送日志增量
- [x] 复用现有 MCP Manager 的启动、停止、巡检和 watch.log
- [x] 独立安装到当前用户目录，并创建桌面快捷方式
- [x] 使用短命 Windows / WSL 假进程进行主路径验证，含 PID 重用保护和 SSE 追加日志
- [ ] Windows 桌面快捷方式的真实人工启停与重启验收（须用户观察）

## 边界与后续
暂不默认开启开机自启、自动重启异常程序、远程控制、容器编排、全部 MCP worker 日志聚合。控制台不能暴露到公网。只接管自己启动的 Windows/WSL 进程；既有运行中的服务标为“外部运行”。

验证需要区分自动测试通过与真实服务逐项操作验收。
