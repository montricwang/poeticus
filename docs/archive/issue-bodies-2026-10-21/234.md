| 查询 | URL | 提取观察 |
| --- | --- | --- |

| `绸缪` | https://zdic.net/hans/绸缪 | 成功，返回 9 个编号义项，各附书证，如《诗·唐风·绸缪》《庄子·则阳》；另含“国语辞典”3 项；部分百科内容标为会员可见 |
| `綢繆` | https://zdic.net/hans/綢繆 | 成功，拼音、传统字形与书证保留；页面主释义组织与简体字页面不同，不宜把两页当完全等价的规范文本 |

**结构观察**：`绸缪` 的 HTML 结果可保留 `<main><article>...`、`<ol><li>释义 ... <cite>《书证》</cite></li></ol>` 等关系，说明源网页结构有可能支持稳定提取“义项 → 书证”，不需要由 LLM 猜测归属。注意 `<cite>` 当前只是文献标题文字，不是已解析的古籍原文深链接。清洗后的 Markdown 可读，但包含导航、登录提示、重复词义和不同来源的混排内容；直接拿全文入模型会增加干扰。

**响应耗时**：首批 4 个词条分别约 4.35、4.68、4.32、4.32 秒（提取服务报告的单页 latency；并行请求，非 Poeticus 全链路）；`绸缪` HTML 二次提取约 1.77 秒。此数据受网络和缓存影响，不能视作 SLA。

### 有意义的反例和失败

- 《蝶恋花》“晴雪半消花䰒𩮰”需要解释**整个复合词及原诗语境**。汉典“䰒”仅给“马垂鬣”，“𩮰”仅给“同鬃”；不可把两项机械拼为最终注释。
- 交叉搜索发现台湾教育部《异体字字典》「䰒」页面直接给出“䰒𩮰：朦胧不清楚”，并引晏几道本句：https://dict.variants.moe.edu.tw/dictView.jsp?ID=111157 。**该页是外部补充线索，不是汉典命中；TinyFish 按该 URL 请求返回 404，需后续复核可访问性。** 教育部教育百科亦有该条：https://pedia.cloud.edu.tw/Entry/Detail?title=䰒 ，其授权标注 CC BY-NC-ND 3.0（不得当成汉典 CC0 内容）。
- 一次从本轮执行容器使用 Python `requests.get` 直接访问汉典时，环境 DNS 解析失败，**与汉典返回拒绝访问不同**；故尚无直接 HTTP/BeautifulSoup 与 TinyFish 的公平对照。

### 七个真实诗文词语

| 词与真实语境 | 汉典页面 | 萌典 `/a/{词}.json` | 有意义的差异与风险 |
| --- | --- | --- | --- |
| 綢繆：《诗经》「绸缪牖户」 | 命中，缠缚、深情、花繁等 | 命中，3 个义项及各自书证 | 两边含教育部同源国语辞典内容；非独立证据 |
| 葳蕤：张九龄「兰叶春葳蕤」 | 命中，草木茂盛及委顿义 | 命中，2 项，含张九龄原句和《红楼梦》不同语境 | 不要把《红楼梦》的「懒散」义应用到张九龄 |
| 觱篥：李颀《听安万善吹觱篥歌》 | 命中，管乐器及引文 | 命中，吹管乐器及悲篥/篳篥等别名 | 异名归一有价值，但未独立验证古代乐器考据 |

| 闌干：岑参「瀚海阑干百丈冰」 | 命中，纵横、栏杆、泪横流 | 命中，栏杆、纵横散乱、星光横斜，附不同诗词书证 | 对每一句分辨语义，绝不可统一翻译成栏杆 |
| 嬋娟：苏轼「千里共婵娟」 | 命中，美人、姿态、月亮 | 命中，3 项且引苏轼原句 | 结构化多义项使「按诗句选择月亮义」可测 |

**实测覆盖口径**：汉典 6/7 整词查询成功；萌典 JSON 6/7 成功；此成功数仅指返回所请求页面/词条，不是字词解释正确率，更不等于两家互相独立印证。未全面逐词检验教育部两个原站，不应给它们列 7/7 命中率。

### 来源、同源关系与互补

1. **萌典提供现成官方结构化 API**：https://www.moedict.tw/about.html 。例如 `https://www.moedict.tw/a/嬋娟.json` 返回 `h[].d[].f`（定义）、`h[].d[].q`（书证）、`h[].p`（读音）；`f/q` 原始内容带内链标记，应由适配层解析，不直接展示标记。官网注明可用于 Web、App、研究，支持 CORS；**API 接口为 CC0，但词典正文来源是教育部《重编国语辞典修订本》，按 CC BY-ND 3.0 台湾授权**，不应混同。公开产品复用、转换和展示仍须核对授权条款及必要署名。
2. **汉典并非完全独立第二套释义**：其「国语辞典」板块对照教育部/萌典常基本同源。汉典自有其他义项、引书及生僻字页也值得使用。示例：`https://zdic.net/hans/菡萏` 与 `https://zdic.net/hans/闌干`；已有汉典自述 CC0 页面 `https://zdic.net/terms/`，但站内第三方源文权利需区分。
3. **教育部《重编国语辞典修订本》是上游对照，不是第 3 个独立投票者**：`https://dict.revised.moe.edu.tw/dictView.jsp?ID=122610`（綢繆）、`?ID=60852`（闌干）、`?ID=82057`（菡萏）、`?ID=18270`（觱篥），公开网页索引可以读取，核心义项与萌典一致。
4. **教育部《异体字字典》真正互补**：`https://dict.variants.moe.edu.tw/dictView.jsp?ID=111157`（䰒：字条载「䰒𩮰」=朦胧不清楚，并有晏几道词句）；`https://dict.variants.moe.edu.tw/dictView.jsp?ID=68664`（萏：记《说文》未发/已发有关旧义及字形资料）、`?ID=68622`（菡：异体映射），能补**罕见字形、正异字对应及历代字书线索**。不是通用词语释义 API 的替代品。
5. **访问路径差异**：同一批 `TinyFish fetch_content` 中萌典 6 个 JSON 词条成功（报告约 0.69–0.79 秒/条），汉典 6 个 HTML 词条成功（报告约 2.27–2.50 秒/条）；两个教育部原站的四个直接 URL 用该提取工具均返回 `page_not_found`，**但公开网页搜索/网页阅读可以检索这些具体页面**。不能由某提取服务的 404 判断教育部官网不存在或词条不存在，也不能把这些计为已验证稳定网页提取。延迟为提取服务报告的单条时长，不是生产 SLA 或等成本的端到端测试。
