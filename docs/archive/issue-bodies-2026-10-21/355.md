## 当前目标与阶段（2026-10-20）

将 [#346 / PR #353](https://github.com/montricwang/poeticus/pull/353) 的公开 API 调查转换为 **Poeticus 现有 ReAct Agent 可以自主调用的少量工具**。本轮先接较有价值的能力，**不一次性注册所有 CNKGraph API**，待统一的真实对话验收再调整工具数量、描述与使用策略。

现已接线、但尚未完成真实 LLM 统一交互验收的 5 个新研究工具：

| 工具 | 用途 |
| --- | --- |
| `analyze_ci_meter` | 词律校验，钦谱/龙谱、变格与错韵 |
| `lookup_ci_tune` | 词牌名称/别名搜索，词谱详情与各体式 |
| `lookup_rhyme` | 韵书目录、指定韵部字表与字表收录验证 |
| `resolve_entities` | 文本实体候选标注、人物/地名等知识图谱 ID |
| `search_classical_books` | 古籍关键词检索、书卷与短命中上下文（原 #355 首批） |

暂不接：跨版本作品 ID 自动映射、直接把外部标注写入主库、所有生平接口、类书批量读取、返回数 MB 的单字综合查询、CNKGraph 整库下载与前端图谱 UI。

## 约束

- 第三方公开 API 仅允许非商业研究学习；**只有本地隔离环境明确开启 `POETICUS_CNKGRAPH_RESEARCH_TOOLS_ENABLED=true` 才注册这五项工具，公开 Web/Railway/Tunnel 默认禁止开启**。产品公开调用及长期缓存前需另行取得许可。
- 保持原有 Evidence Layer、`lookup_allusion`、`lookup_reference`、`search_documents`、作品数据库主权；模型自己判断是否调用，不增加固定 Planner。
- 外部响应限制大小、控制返回给模型的上下文，保留来源/外部 ID、未命中/异常的区别，不把形式押韵等同宋代合乐，也不把关键词匹配直接当原始出处。
- 韵书接口按韵部查询；厂商 `Rhyme/Find` 单字查询的真实响应可达数 MB，本轮不直接接入此高负载端点。
