## 2026-10-14：合并 Context Construction 学习与候选证据完善（承接 #280）

### 学习范围与工程边界

1. **Retriever 候选与 Agent Context 是两回事**：先取得相关 Work/Chunk，再选择真正应向 LLM 展示的证据。
2. **上下文扩展**：对比只返回命中 Chunk、相邻句/联、短作品全文，以及长篇古文的受限窗口；不默认把所有全文塞给 LLM。
3. **归属与 Grounding**：保留并核对 `work_id`、题名、作者、时代、`source_record_id`、命中位置及实际正文；缺失不得猜测，字面相似不能直接断言化用。
4. **证据组织与成本**：多条命中归并、重复候选处理、呈现顺序、无关证据噪声、Token 预算与截断；区分检索排序和回答证据的组织。
5. **给 Agent 的可判断信息**：区分可观察的文字对应、结构意象相似、时间关系、可核实史料与待证推论。

## 2026-10-08 补充：引用忠实度与文学推论的独立验收

用户的原始 AI 回答将多个陆游检索命中解释为“陆游自己反复使用句子，非借自他人”。这里除缺乏候选全文外，还犯了**证据强度升级**的错误：

- Tool 返回若只是片段 + 作品标签，不能未经 Work 全文核验就说某句“出自”某首具体作品；
- 候选记录数不等于独立作品数，也不证明作者确有自我复用；
- 即使存在同作者重复句，也不能直接否定陆游与杜甫的先后文本对应；
- “文字和构句高度对应”“有可能化用”“有史料记载确曾化用”要分开陈述；年代只能限制可能的影响方向，不能单独证明或证伪化用。

新增验收 Case：给定陆游「双双新燕飞春岸，片片轻鸥落晚沙」与杜甫「娟娟戏蝶过闲幔，片片轻鸥下急湍」，Agent 应能识别成联的并行结构和「片片轻鸥」的精确重合，在不臆造文学影响史料的前提下比较两个作品语境；同时不能把错误归属给《送叶梦锡》或把两个别名记录称为陆游重复使用。应分别评测 **retrieval correctness / source grounding / literary reasoning**，避免用一个总分掩盖故障层次。

## 问题（2026-10-07 真实检索 Case）

用户提问陆游《鹧鸪天》「片片轻鸥落晚沙」与前人诗句的关系。文本比较不仅仅是查到杜甫年代更早，还需要看到相邻句及作品语境：

- 陆游《鹧鸪天》其六：「**双双新燕飞春岸，片片轻鸥落晚沙**。」
- 杜甫《小寒食舟中作》：「**娟娟戏蝶过闲幔，片片轻鸥下急湍**。」

这两组句子有可比较的句法形式、叠字、鸟类意象与场景安排；但判断“文本对应很强”仍不同于证明陆游确实有意引用杜甫。比较还要看两首作品整体语境、表达功能和可核实的外部文献证据。

## 现行实现的证据缺口

- `backend/ai/graph.py` 把 **当前阅读作品的全文** 放进 Agent 上下文；
- `backend/retrieval/serving.py` 构造 `ServingCandidate.text` 时只取 `best.hit.text`（sentence 或 clause Chunk）；
- `backend/retrieval/server.py` / `backend/retrieval/client.py` 当前候选契约没有完整候选作品正文，也没有稳定的前后文；
- `backend/retrieval/metadata_store.py` 的 Work metadata 当前只存 title/author/dynasty/source_record_id/content_fingerprint，没有 full content 可直接读回。

因此“Agent 应结合全文判断”这条 Prompt **并不能保证 Agent 实际拿得到被检索作品的完整上下文**。

## 待设计（不要立刻把所有大作品全文塞入 Tool）

- [ ] 把 **短文本召回** 和 **候选证据扩展** 视作两个不同步骤：先召回 Top-K，只有需要推断互文关系的候选才补上下文；
- [ ] 比较轻量方案：返回命中句相邻句 / 所在 couplet 与 Work 内位置；对短诗词再选择性补全篇，对长文本限制窗口；
- [ ] 确保取回的上下文与 `work_id`、`source_record_id` 和实际正文一致；不得在 #151 / 题文错配定位前默许错误归属；
- [ ] 对 Agent 回答保留 **字句相似、结构/意象对应、前后年代、可证实的引用关系** 四种不同强度的依据，不因年代更早就直接断言化用；
- [ ] 加入陆游 ↔ 杜甫真实 Case，检验 Tool 提供上下文后能否解释 **两组句子怎样对应、在两首作品中各有什么作用、哪些判断仍属推测**；
- [ ] 用 Tool payload 大小、延迟和实际回答质量评估方案，不预先增加独立复杂的多阶段框架。

**边界**：这里讨论的是文学分析所需的证据量，不是让 ANN/BM25 直接判定引用、影响或作者意图。与 #151 去重、题文错配是独立问题。
