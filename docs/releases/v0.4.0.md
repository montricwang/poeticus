# Poeticus v0.4.0 — 诗词阅读与伴读体验

v0.4.0 为 Poeticus 的诗词阅读器增加了逐句排版、自适应居中、上下首导航和深浅主题设置，并完善桌面、平板和手机上的阅读与伴读布局。

**在线体验：** https://poeticus-web-production.up.railway.app/

## 新增功能

- **逐句分行与标点弱化**：诗词正文依据现有句读在界面中逐句分行，行内及行末标点使用独立的浅色／深色颜色。复制和划词提问仍使用完整原文，保留字符顺序与 UTF-16 选区位置。
- **自适应光学居中**：根据每行实际渲染宽度及长短句分布，动态调整整组诗句的位置。字体加载、阅读区域缩放时重新测量，窄屏布局带有位移保护。
- **上一首／下一首**：阅读区新增连续浏览按钮，按数据库原书顺序查找相邻作品，支持跨目录分页。首尾作品自动禁用对应按钮；切换时展示轻量过渡和加载反馈。
- **主题设置**：页眉新增设置菜单，支持浅色、深色及跟随系统，保留选择偏好并响应系统外观变化。浅色使用暖白 `#FAF9F6`，深色使用炭黑 `#151411`。

## 阅读与伴读界面

- **更舒展的诗词排版**：调整正文行高、字距、来源段间留白、滚动条和标点对比度。
- **响应式双栏**：重新组织阅读区、伴读区与独立分割线，改善目录开合、短词、长词、空对话和长回复等状态的空间分配。
- **统一的 2px 书页式分割线**：覆盖阅读导航、伴读工具栏、消息与输入区。手机阅读导航恢复横线；手机端空对话也能看到输入区域的分界线。
- **更清晰的滚动体验**：统一作品目录、正文、聊天和赏析的细滚动条；阅读区在有隐藏内容时显示顶部／底部渐隐。
- **对话与赏析细节**：提高对话正文字号、压缩输入区和赏析章节留白，增加复制／编辑／重新生成的定制 Tooltip。AI 消息署名统一显示为「Poeticus」。
- **赏析阅读位置恢复**：同一首作品在「对话」和「赏析」之间切换时，返回赏析可以继续阅读之前的位置；切换作品或重新生成赏析会重置位置。

## 技术实现与验证

- 新增只读 `GET /api/poems/{poem_id}/neighbors`，按 `source_order` 查询前后作品。
- 诗文展示由 `PoemBody` 和 `poem-layout` 处理视觉分行、标点片段与原文偏移映射；保留划词引用、复制和 AI 上下文的数据契约。
