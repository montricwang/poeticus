# Poeticus v0.8.0 — 文学批评方法与流式伴读

v0.8.0 为诗词伴读加入十四类文学批评方法，让 AI 除了查询字词和典故，还能从作品的语言、结构与艺术表现入手组织赏析。同时改进了回答的流式显示与重新生成体验。

**在线体验：** https://poeticus.app/

## 新增功能

- **十四类文学批评方法**：新增炼字、声律、意象、章法、叙述、时空、典故、互文、背景、史实、寄托、审美、假设比较与异说辨析等分析指引，帮助伴读围绕具体词句提出更有层次的解释。
- **按需选择与组合**：AI 根据提问选择相关方法，必要时结合多种分析角度；简单释义无需套用复杂步骤。需要考证原典、年代或典故时，仍可配合已有的文献检索工具。
- **更灵活的工具调用**：文学方法的读取不再挤占文献查证次数，Agent 的工具调用上限也可按使用场景调整。

## 阅读体验

- **回答逐字淡入**：伴读正文随生成逐步显现，调整了 Markdown 内容的呈现方式，减少文字出现时的突兀感。
- **重新生成更连贯**：重新生成的内容直接在原回答位置流式展示，不再出现第二个临时回答框，也移除了重复的进度提示。
- **消息布局更稳定**：优化流式输出期间的内容布局与高度变化，让长回答的阅读过程更平顺。

## 修复与改进

- 完善赏析接口对空白、过长输入和上游错误的处理。
- 整理十四类方法的适用范围与相互关系，便于后续持续改进赏析质量。

## 使用说明

文学批评方法仍在持续试用和完善中；涉及具体出处、版本与史实的解释，仍应核对原始材料。受 Railway 平台故障影响，**GitHub v0.8.0 已发布，公开网站是否同步更新以实际部署为准**。
