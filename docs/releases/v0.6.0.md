# Poeticus v0.6.0 — 阅读动效与视觉细节

v0.6.0 为诗词首页、馆藏搜索和阅读室增添了更自然的过渡动画，改进桌面与平板的竖排布局，并为原文引用加入中国红下划线。

**在线体验：** https://poeticus.app/

## 新增功能

- **首页入场动画**：每日推荐的竖排词文逐列浮现，中间分割线从中央向两侧展开，搜索标题与输入框依次出现。从阅读室返回首页时也会播放入场动画。
- **搜索过渡**：提交搜索时，每日推荐渐隐，搜索框平滑上移，结果列表逐项出现；清除搜索后，首页推荐与分割线按顺序恢复。
- **原文引用下划线**：划选词句并加入引用后，阅读区对应原文下方出现细红线，方便在原文与伴读讨论之间对照。

## 修复与改进

- **竖排布局**：桌面和 iPad 上的诗文与「读这首词」印章整体居中；长词优先保留完整段落，并在首页清晰标注节选。
- **页面显示**：改善 Safari 字体加载期间的等待与首屏显示，缩短首页和阅读室的入场等待。
- **视觉统一**：引用、链接、未读提示与错误提示采用一致的中国红强调色，深色主题同步调整；阅读室统一作品标题、作者、小序的字号、字重和间距。
