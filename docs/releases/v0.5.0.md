# Poeticus v0.5.0 — 首页与阅读布局

v0.5.0 新增了诗词首页、每日一词和馆藏搜索，调整了桌面与手机的阅读排版。

**在线体验：** https://poeticus.app/

## 新增功能

- **每日一词**：首页从 3491 首词作中按北京时间每日推荐一首；同一天刷新页面仍显示同一首词。点击「读这首词」进入阅读室。
- **竖排推荐**：首页展示竖排词文，手机根据可用空间调整断行；长词在首页展示节选。
- **首页搜索**：可直接按词人、词牌或词句搜索馆藏。搜索区域采用「美要眇兮宜修」题头与简洁的横线样式。
- **阅读与目录布局**：桌面阅读版心重新调整，目录根据可用高度分页；手机和桌面分别使用适合各自屏幕的页面布局。

## 修复与改进

- 修复部分 iPhone Safari 页面上竖排推荐正文无法显示的问题。
- 改进长词在窄屏上的节选、断行与印章位置。
- 调整阅读区短词的垂直位置、小序换行和目录交互。
