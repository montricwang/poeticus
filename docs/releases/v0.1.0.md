# Poeticus v0.1.0

**Poeticus 第一个公开体验版本。** 围绕宋词原文进行搜索、阅读、划词追问和 AI 赏析。

**在线体验：** https://poeticus-web-production.up.railway.app/

## 已发布能力

- **3491 首宋词**：PostgreSQL 作品目录、作者/词牌/文本检索、分页、单首作品正文与切换阅读；保留作品原 UUID 和顺序。
- **宋词 AI 伴读**：围绕当前词作连续提问、引用划词片段、SSE 流式回答，Agent 按需调用 CNKGraph 典故参考检索。
- **整首赏析**：生成白话译文、词语注释与文学赏析。
- **工程部署**：React、Vite、TypeScript 前端 + FastAPI、LangGraph 后端，Railway Web + PostgreSQL，同源 HTTPS 入口。
- **费用与安全边界**：服务器侧 AI 开关、全站每日配额、客户端分钟限速、单实例并发上限、请求体限制、模型输出 Token 限制、工具调用预算与默认不自动重试。额度耗尽后作品阅读仍可用。

## 验收与已知边界

- GitHub 主分支 CI 已通过，包括 Python 测试、前端 lint/build、Node 测试及生产依赖审计。
- [公网只读验收](https://github.com/montricwang/poeticus/actions/runs/37176951820) 已使用无凭据请求验证：首页、`/health`、`/api/info`、作品目录 **total=3491** 和单首完整正文。
- SSE 问答、整首赏析、服务端限流曾在受密码保护的 Railway 真实环境成功测试；公开后的匿名 AI 调用受共享额度保护。以上事实**不等于所有客户端、断连或异常场景已穷尽验证**。
- 所有作品均标记 `imported_unreviewed`，未完成逐首人工校勘；AI 解释、译文和典故检索结果仍可能出错。
- 无账户注册、跨设备会话同步或服务端永久对话记录；阅读和历史记录主要保存在本机浏览器。
- 首版优先桌面阅读；字体体系和窄屏布局等改进后续处理。
- 公共仓库不包含私人商业 EPUB、出版物注评来源、私有语料证据与数据库/模型密钥。
- 匿名 AI 为有额度的演示能力，**不是无限免费模型接口**；模型余额和请求次数不构成精确人民币费用上限。
