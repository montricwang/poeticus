# Poeticus v0.1.0

**Poeticus 的第一个公开版本。** 收录 3491 首宋词，支持搜索、阅读、划词提问和整首 AI 赏析。

**在线体验：** https://poeticus-web-production.up.railway.app/

## 主要功能

- **作品库与检索**：3491 首宋词存入 PostgreSQL，可按作者、词牌和正文搜索，支持分页、切换作品和阅读全文；保留作品原 UUID 与顺序。
- **AI 伴读**：可以围绕当前词作连续提问，也可以引用划选的原文。回答通过 SSE 流式返回，Agent 可按需调用 CNKGraph 查询典故参考。
- **整首赏析**：生成白话译文、词语注释和文学赏析。
- **部署**：React、Vite、TypeScript 前端，FastAPI、LangGraph 后端；运行在 Railway Web + PostgreSQL，通过同一 HTTPS 入口提供页面和 API。
- **匿名 AI 保护**：服务端可以关闭 AI，并设置每日共享额度、客户端分钟限速、单实例并发上限、请求体大小、模型输出 Token 上限和工具调用预算。AI 额度耗尽后，作品阅读仍然可用。

## 验证

- GitHub 主分支 CI 已通过，包括 Python 测试、前端 lint/build、Node 测试和生产依赖审计。
- [公网只读验收](https://github.com/montricwang/poeticus/actions/runs/37176951820) 使用无凭据请求验证了首页、`/health`、`/api/info`、作品目录 **total=3491** 和单首完整正文。
- SSE 问答、整首赏析和服务端限流曾在受密码保护的 Railway 真实环境中成功测试；公开后的匿名 AI 调用受共享额度保护。

这些验证覆盖了主要链路，但没有穷尽所有浏览器、断连和异常场景。

## 已知限制

- 所有作品目前均标记为 `imported_unreviewed`，尚未逐首人工校勘；AI 解释、译文和典故检索也可能出错。
- 目前没有账户注册、跨设备会话同步或服务端永久对话记录；阅读进度和对话历史主要保存在本机浏览器。
- 首版优先保证桌面阅读，字体体系和窄屏布局仍需继续调整。
- 公共仓库不包含私人商业 EPUB、出版物注评来源、私有语料证据以及数据库或模型密钥。
- 匿名 AI 只有有限的演示额度，不是无限免费的模型接口；请求次数和模型余额也不能作为精确的人民币费用上限。
