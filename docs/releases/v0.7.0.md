# Poeticus v0.7.0 — 词学研究与知识工具扩展

v0.7.0 扩展了古典诗词阅读中的文献、字词、格律和网页研究能力，并完成新一批文学批评研究资产的整理。阅读首页的题名显示与印章交互也得到改进。

**在线体验：** https://poeticus.app/

## 新增功能

- **词学文献检索**：新增本地 Document Corpus，使用 PostgreSQL、pgvector 与 BM25 混合检索《人间词话》《白雨斋词话》等历代评论，返回书名、卷则和源文定位。私人研究库在本次扩展至 **6 部文献、1152 条检索段落与向量**。
- **词谱与韵律研究工具**：接入五项 CNKGraph 研究能力，覆盖词牌与词谱查询、词律校验、韵部查询、古籍短句搜索和实体识别。
- **联网资料查证**：新增可选的 DeepSeek Search / Fetch 工具，支持查找外部公开网页、读取搜索结果中的文章内容，并为资料提供可核对的来源链接。
- **字词与古籍查询**：新增萌典释义查询、维基文库页面搜索与原文读取。可从原文中的疑难词语、人物或典籍线索继续查证。
- **古典语汇离线检索**：完成《詩詞曲語辭匯釋》的私人数字化检索资料，覆盖 **537 个词头**，保存原始页面版本和来源信息，提供 SQLite 全文查询。

## 文学研究与评测

- **文学批评方法研究**：完成《唐宋词鉴赏辞典》**1505 份研究卡**的首轮整理，提取 **7927 条方法动作**和 **23834 条证据索引**，为后续批评方法归纳与跨作品验证提供可追溯的研究素材。
- **综合阅读评测**：建立 Reader 100 题库及真实 Agent 测试入口；首轮 20 题检验了 **14 项工具的注册与调用链路**，20 题均获得回答，完整结果可供后续证据质量复核。
- **文献导入质量**：补充 EPUB 图片代字与图表预检规则，增强词话、韵律著作及古籍电子文本的来源完整性检查。

## 阅读体验与细节

- **首页题名**：完善贺铸作品的首页题名显示，按作品元数据使用「寓声」。
- **印章交互**：统一「读这首词」按钮的边框与悬停填充色，保持一致的中国红视觉效果。

## 使用范围

CNKGraph、DeepSeek Web、萌典和维基文库研究工具采用**按需启用**配置。CNKGraph 相关接口限于获许可的本地非商业研究；DeepSeek 联网工具按供应商接口计费。六部词学文献和《詩詞曲語辭匯釋》保存在私人研究环境中，公开网站继续提供现有的阅读与伴读功能。

文学研究卡与来源文献保留在私人数据目录；研究方法的进一步归纳、自动记忆与 Critic 人格演化将通过独立评测逐步推进。
