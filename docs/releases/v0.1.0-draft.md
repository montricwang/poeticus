# v0.1.0 — 发布说明（草稿，**未发布**）

Poeticus 首个面向访客的宋词 AI 伴读版本。围绕作品正文进行阅读、检索、划词追问与整首赏析。

## 包含内容

- **3491 首宋词**：PostgreSQL 存储，目录分页、词人/词牌检索、完整正文与词序；线上目录数量已实际核实为 3491。
- **AI 伴读**：围绕原作连续提问、划词引用、SSE 增量回答，按问题需要查询典故参考资料。
- **整首赏析**：生成白话译文、词语注释、文学赏析；修复真实环境下的 JSON 赏析失败。
- **云端部署**：FastAPI + React/Vite 同源 Web，Railway PostgreSQL，数据库迁移和健康检查。
- **费用/滥用保护**：付费端点默认关闭；生产环境由人工开启。服务端请求体/历史长度限制、每客户端频率限制、并发上限、PostgreSQL 持久每日请求配额、模型输出 Token 上限、工具调用次数限制。
- **安全**：预览密码只用于发布前受控测试；正式开放时撤除门禁，但必须继续保留 AI 预算中间件及供应商侧余额控制。前端不包含 API Key；React Markdown 禁止原始 HTML。

## 已知限制

- 全库作品为 `imported_unreviewed`：**未宣称全部作品逐首人工校勘**。模型赏析和典故候选不等于可靠的文献考证。
- 现阶段没有账号登录、服务端对话长期存储或跨设备历史；本地浏览器保存阅读记录。
- 匿名服务存在请求额度；耗尽后需等待配额恢复。单 Web 实例内限速和并发控制；每日数据库请求额度跨实例保持一致。请求次数不是精确人民币成本上限。
- 手机端适配和字体细节不构成首发目标，放入后续版本。
