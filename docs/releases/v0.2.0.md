# Poeticus v0.2.0

v0.2.0 收录了 Poeticus 上线后的第一轮工程整理和阅读排版调整。3491 首宋词和 AI 伴读仍沿用 v0.1.0 的公开能力；这次主要修改代码结构、中文字体和阅读页面。

**在线体验：** https://poeticus-web-production.up.railway.app/

## 工程整理

- 将原先集中在 `App.tsx` 里的聊天会话、持久化、赏析和作品加载拆到独立模块，`App` 继续负责页面协调。
- 将 FastAPI 与 AI 代码统一整理到 `backend/`，随后删除已经不再使用的根目录兼容入口。
- 整理 EPUB 导入、诊断和重建工具，删除一批临时脚本与旧静态数据。
- 集中管理运行时配置和前端可见的能力限制，避免同一项限制在前后端各维护一份。
- 清理预览阶段遗留的兼容代码、过时测试语义和无用资源。

对应合并：#91、#92、#93、#94、#95、#96。

## 字体与阅读页面

这一版确定了 Poeticus 的基础字体分工：

- 拉丁 UI：Inter Variable
- 苹果设备中文 UI：PingFang SC
- 其他平台中文 UI：Noto Sans SC Variable
- 诗词正文：Noto Serif SC Variable
- 生僻字补充：HanaMin

排版继续沿用“**诗歌是出版物，界面是软件**”的原则：作品正文使用宋体体系，按钮、搜索、状态提示等软件界面使用无衬线字体。

同时调整了词牌、小序、作者和正文之间的间距，并将阅读器的字号、行高、字距等参数集中到 `.poem-reader`，后续可以在一个位置继续调试。

字体比较实验 #97 在确定正式方案后关闭，没有合并。正式字体与排版改动见 #99、#100。

## 其他修复

- 修复局域网 HTTP 环境下 `crypto.randomUUID()` 不可用时无法初始化会话的问题，在浏览器支持范围内使用 `crypto.getRandomValues()` 作为 fallback（#98）。

## 没有进入 v0.2.0 的改动

v0.2.0 的标签停在响应式重构之前。

发布时，手机 / iPad / 桌面的阅读讨论布局仍在 #103 中开发。#103 后来已经合并到 `main`，但它和之后的移动端、赏析与动画调整都不属于 v0.2.0 这个 Release。

因此，查看 v0.2.0 时应以 Release 标签对应的代码为准，而不是当前 `main`。

## 仍需继续处理

- 手机、iPad 与桌面端的阅读 / 讨论布局还需要继续真机验证和调整。
- iPhone 目录分页、横向溢出与选区更新仍有独立问题需要处理（#85、#86）。
- 上下阕间距目前仍和正文换行、行高绑在一起，后续需要拆开。
- “一句一行”以及多 DOM 节点下的选区坐标映射还没有进入当前展示层。
- 生僻字跨字体 fallback、EPUB 非正文结构分类、AI Eval / Evidence / RAG 继续保留为后续专题。

## 发布范围

- v0.2.0 对应的 Release 标签不会随着后续 `main` 更新而移动。
- 3491 首作品仍是导入后尚未逐首人工校勘的公开语料。
- AI 译文、解释和典故检索可能出错。
- 匿名 AI 仍受共享额度、限速与并发保护。
