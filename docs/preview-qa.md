# Railway 临时 UI 集成预览验收

本分支专供测试，**不要合并到 main**，也不改变 Draft PR #72 / #75 / #80 的验收状态。

## 组合来源

- 基底：`chore/public-deployment`（#80），包含 FastAPI/React 同源部署、Railway PostgreSQL 合成测试数据、HTTP Basic Auth 与只读预览保护。
- UI：`feat/editorial-three-column`（#75），自身包含依赖 PR #72 的可折叠目录和多词搜索。
- #75 相对 main 的 12 个改动文件和 #80 相对 main 的 8 个改动文件**没有文件路径冲突**；此次只将 #75 的最终文件复制进独立预览分支，不动原 PR，也没有合并主分支。

## 浏览器验收（预览只有 3 首合成数据）

1. 输入 Railway 临时 Basic Auth 凭证后，应能看到左侧**可收起**的两行作品目录、中间**无 Card 外框**的原文、右侧**无气泡**的伴读区。宽屏有细竖线分栏，窄屏目录改为抽屉。
2. 目录搜索「测试作者」，结果为 3 首；搜索具体测试作品题名可筛选；点击作品后正文跟随变化，浏览器刷新仍能回到有效作品。
3. `GET /api/poems` 由 PostgreSQL 返回 3 条测试记录，单首详情可展示分段原文；`/health` 200。
4. 在只读模式下尝试问答或赏析，应该得到受控的 503，不会真的调用模型，因此**不能在本次验证 SSE 和真实 AI 功能**。
5. 检查浅色、深色、系统主题以及窄屏抽屉、阅读选区是否正常；合成短词并不能覆盖所有正文长度和文字校勘问题。

此临时分支是用来评价 UI + 云端数据库是否协同运行的，不代表 v0.1.0 已正式发布。测试完成后应单独评估 #72/#75 再决定是否合并；#77 公网费用保护仍未完成。
