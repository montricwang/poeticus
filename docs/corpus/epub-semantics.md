# EPUB 词作语义抽取规则（MVP）

本阶段只面向《历代名家词集精华录》中**作者词集**，不把《词品》《唐宋词格律》等论著拆成 Poem。既不研究成套词，也不重建词牌异名体系。前端现有作品 JSON 另有 Schema，暂不受本 PR 影响。

## 最终抽取字段

- `id`, `author`, `collection`, `source`；
- `tune: str | null`：词调；首首若出现无法解释的「又」，置空并附 warning；
- `title: str | null`：便于统一展示的词题，没有则为空；
- `content.text`、`content.prefaces`、`content.annotations`、`content.commentaries`：字符串数组；
- `warnings`：仅放无法自动处理的情况、图片字等。

`heading`/原书写法只在提取函数的**临时 section** 中保留，不进入最终 Poem；需要重新检查时回到私有 EPUB。不会为《西湖念语》、套词、别名另设字段。

## 已确认的来源特征

| 来源 | 标题规则 | 小序规则 |
| --- | --- | --- |
| 苏轼、辛弃疾、晏殊、欧阳修 | 标题内较小 `span.font1` 或 `span.font2` 是词题 | 苏轼、辛弃疾在首个正文段落之前的指定楷体缩进段落为小序 |
| 黄庭坚、姜夔、李清照 | 标题中楷体 `span` 为词题，李清照允许换行 | 黄庭坚楷体缩进段落、姜夔 `p.kindle-cn-ref` 为小序 |
| 秦观、周邦彦、陆游 | 标题内第二文本片段为词题 | 直接紧接标题的指定 `p.kindle-cn-ref`/`ref2` 为小序候选 |
| 纳兰词集 | `h2 span.small` 为词题 | 目前无确定的独立小序模板 |
| 柳永 | `h2` 词牌后紧接的 `p.kindle-cn-para-center.kindle-cn-kai` 为词题 | 暂无稳定的小序模板 |
| 贺铸 | 标题中前半是贺铸所命名的名称，后面小字为旧词调；统一输出 `tune=后半`、`title=前半` | `p.kindle-cn-ref` 仅在正文开始前归为小序 |
| 温庭筠、韦庄等 | 单段标题只提供词牌 | 无独立小序证据则不推断 |

通用规则：直接 DOM 子片段分隔，不靠词牌表截字符串；单独「又」继承同一导入序列前一首已解析词牌；注释 `◎`、评论 `◆` 按文本明确标记分类。姜夔 `p.kindle-cn-para-no-indent1` 带四位年份是编辑编年标签，不写入上一首正文。《西湖念语》不是作品，跳过它及附随注释。

## 不做与验收

- 不新增 `title_raw`、`suite_id`、词牌别名字段、独立组序格式。舍弃非作品内容属于**有意取舍**，不是把它混进下一首。
- 不擅自纠正文句或替换不可识别异体字，图片字保留占位符进入现有映射流程。
- 数据审计按各作者/卷与目录比数量、检查空正文，并对多标题片段、未能继承的「又」产生 warning；公开测试使用合成 HTML。
- 暂不将导出的现代评注/私有报告提交仓库。需由本地 EPUB 运行后人工抽查首尾和典型作品。凡未确认的版式不新增隐性猜测。
