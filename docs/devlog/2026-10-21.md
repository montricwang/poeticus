# Poeticus 开发日志｜2026-10-21

## 《唐宋词鉴赏辞典》：从方法统计走向 Skill

完成 1505 篇赏析的格式统一与引文定位复核，汇总出 **7927 条方法分析、14 类标签**；统计报告见 [词评方法概览](../research/critic-methods-overview-2026-10-21.md)，研究任务由 [#372](https://github.com/montricwang/poeticus/issues/372) 接续，首轮逐篇研究 [#354](https://github.com/montricwang/poeticus/issues/354) 已关闭。

今天重点研究 `INTERTEXT`（互文）：全库这一类有 **949 条方法记录，涉及 904 篇赏析**。先对其中约 200—225 条进一步抽取实际论证动作，整理子方法、适用条件、步骤与反例；这是**该类的部分精炼**，不是 949 条全部完成，更不是全部 14 类的 Skill 已建立。原始赏析、研究记录与引文坐标继续留在私人数据区，不上传现代版权文本。

原先尝试传统向量聚类，但相似度难以稳定对应文学批评中的具体动作；现阶段改由模型结合原文案例分组、写出可执行步骤，再抽查分组边界，不继续为描述性统计增加复杂度。

## 互文 Skill 的首轮试验

在固定小题集上，将当前 DeepSeek 基线与不同篇幅的互文方法提示比较，并分别测试单题工具预算 2 与 5。完成一轮针对方法表现的解盲后复核：12 题 × 2 种预算 × 4 组回答，共 96 份。评分时重点看是否发现有意义的文本关系、能否比较异同、是否据此推进解释；事实考据与来源可靠性作为独立风险，不全部算作互文 Skill 的责任。

不同提示版本有细微差别，其中标准版略高于基线，但样本少、基础得分高，不足以判定稳定提升。此前混合题集还混合了检索、考据与表达问题，不能直接归因于互文方法。**这一轮只能评价互文 Skill 的初步可用性，不能评价 14 类方法体系。** 详细逐题回答、盲评记录与解盲映射保留在私人实验产物中。

## 今日决定

1. **四层架构继续建设**：Skills 教模型怎样阅读与论证；Library 保存可查来源；Notebook 保存 Critic 自己可修订的判断；Persona 保留研究原则与逐步形成的审美偏好。方法库的建设不以当前一轮 A/B 分数显著提高为先决条件。
2. **区分建设和上线**：可以先形成候选 Skill 库；纳入在线 Agent 前仍做最小试用、版本记录和退化检查。不能因为 Skill 已生成就声称其效果得到验证。
3. **方法扩展先求覆盖**：暂不优先将 `INTERTEXT` 从约 225 条推到 500+；明天先为其余类别各整理首版方法。等全局地图成型，再回到案例稀疏、分组含混、出现明显失败的类目继续深挖。
4. **评测服务于诊断**：暂不急着扩到 100—200 题做大规模排名。先保留代表性例题与坏案例；待多类 Skill 可组合后，按结构分析、互文、词句细读、事实/证据、表达等能力分别评测。
5. **工具预算是独立配置问题**：当前 2/5 次实验已做；将上限改为环境与脚本可配置继续由 [#390](https://github.com/montricwang/poeticus/issues/390) 处理，不阻塞方法库建设。

## 2026-10-22 安排

- **先统一产物格式**：每类保留来源记录 ID、子方法名称、触发条件、操作步骤、能说明差异的例子、反例/局限、抽核状态；生成简版与详版，两版共享同一事实来源。不得将事实主张、评论者个人意见和操作方法混为一项。
- **分组并行研究**：以 14 类标签为范围，将尚未形成 Skill 的类别分成 3—4 组、交给独立研究对话。每组只写自己的私人草稿及交接清单；统一由主控复核和整理，避免多人争写同一结果或 Git 文件。
- **每类先取代表性样本**：优先覆盖不同子动作、边界与反例，初轮可从约 20—40 条开始，视该类样本密度调整；不机械要求全部类别都精炼 500 条。
- **收口标准**：争取完成 14 类方法的首版目录和候选 Skill 草稿；对未完成、缺原文与不确定类别明确标注。只用少量真实题做冒烟和回归，不将完整效果评测作为明天的交付门槛。
- **后续分层**：Skill 库稳定后，再将来源锚点接至 Library、将实际判断与修订写入 Notebook；Persona 不从现代鉴赏文章中直接抄出价值立场，不启动自动人格更新。

研究跟踪：[方法归纳及试用 #372](https://github.com/montricwang/poeticus/issues/372)、[四层架构 #148](https://github.com/montricwang/poeticus/issues/148)、[Critic 阶段目标 #311](https://github.com/montricwang/poeticus/issues/311)。今天停止继续批处理与扩大评测。
