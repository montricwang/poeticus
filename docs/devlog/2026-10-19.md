## 本地模型：从「能装下」到真正跑通 CPU 与 Intel GPU（素材）

围绕 Poeticus 未来的离线文学分析与 Critic Refine，初步验证了三款本地 GGUF 模型。模型权重均保存于独立的 `poeticus-data/models/`，运行工具隔离在私人数据目录；未改生产 Agent、LLM API 配置或现有 Retrieval 服务。

先使用 WSL + `llama-cpp-python==0.3.36` 做 CPU Smoke Test。Qwen3.5-4B Q4_K_M 加载约 **4.92 秒**，生成简短的苏轼《定风波》中文解释；DeepSeek-R1-0528-Qwen3-8B Q4_K_M 加载约 **16.33 秒**，能够正常生成，但最初的 **96 Token** 输出额度消耗在 `<think>` 内，尚未拿到完整的最终文学回答。这一阶段只证明离线推理链路可用。

随后检查 Intel Iris Xe：**WSL Vulkan 仅枚举到 `llvmpipe` CPU 软件渲染器**，因此改用 **Windows 原生 llama.cpp b11723 + Vulkan**。`--list-devices` 与运行时日志均确实识别 Intel Iris Xe，并分别通过 `-ngl 0` / `-ngl 99` 测试 CPU / GPU。短 Benchmark（单次，不同模型的 Token 长度也不同）：

| 模型 | GGUF 权重 | Windows CPU 生成 | Intel Iris Xe 生成 |
| --- | ---: | ---: | ---: |
| Qwen3.5-4B Q4_K_M | 2.74 GB | 8.97 Token/s | **12.51 Token/s** |
| DeepSeek-R1-0528-Qwen3-8B Q4_K_M | 5.03 GB | 5.93 Token/s | **8.29 Token/s** |
| Ternary Bonsai 2 27B PTQ1_0 | 5.95 GB | 1.09 Token/s | **2.38 Token/s** |

Bonsai 2 27B 从国内 ModelScope 镜像下载并完成 SHA-256 校验。其 **PTQ1_0（1.75 bpw）** 需要 Prism ML 定制版 llama.cpp；安装相容的 `prism-b10772-e8fd209` Windows Vulkan 发行包后，已在核显上**真正生成完整中文回答**。即使权重仅比 8B 大约 18%，核显生成速度也只有约 2.4 Token/s，提示词处理约 1.42 Token/s。极低位量化节省了存储与模型驻留所需内存，**没有同步消除 27B 规模的推理计算成本**；不能直接据此归因于特定硬件或 Kernel。WSL 4 GiB Swap 曾被占满，后续长文评测要限制并发、检查内存与换页。

**已验证**：普通笔记本可以离线运行 4B / 8B / 27B；Windows 原生 Vulkan 可真实调用 Intel 核显；8B 可作为低速本地实验模型。**尚未验证**：8B 的文献提炼、观点归纳、批评与修订的实际质量、长上下文与长时间稳定性、是否优于单轮云端模型；本轮没有进行 LoRA 微调。
