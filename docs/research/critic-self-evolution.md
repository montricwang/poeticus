# Poeticus Critic：自主研究与审美演化（研究设计）

状态：研究提案，尚未验证。日期：2026-10-17。源头：#148。

## 目标与核心假设
不修改底层模型权重，让文学批评 Agent 在离线研究中自主选题、阅读、提出假说、寻找反例、维护长期记忆；检验这些经验是否提升其在未见作品上的解释能力与判断质量。不是意识或模型参数自我进化的宣称。

## 与原有四层结构的关系
- **Persona / Constitution**：保留最小、稳定的证据纪律、独立判断和诚实表达原则；不预设偏爱哪位词人或流派。原则的修改需版本管理和评测。
- **Skills**：提供细读、互文、文献考证、比较、质疑等可调用方法；允许 Agent 自主选择，未来可实验性提出新的 Skill，但须测试后启用。
- **Library**：原典、词话、论文及互联网来源，保存出处、版本和可靠性；自主决定何时检索什么，不取消 RAG。
- **Critic Notebook**：保存有依据的观点、审美倾向、反例、修订史、未解决问题；候选与正式记忆分层，不能无限追加或把自己的旧输出当外部证据。

原 #148 的四层结构是初始支架，不是需要拆除的障碍；需要逐渐减少的是人工硬编码的研究路线。

## 双循环
- **在线对话**：面向用户，按需调用 Library / Notebook，保留用户记忆与 Critic Memory 隔离。
- **离线研究**：自主选题 → 选择材料 → 阅读与检索 → 提出假说 → 证据与反例 → 反思 → 候选札记 / 研究问题 → 独立检验 → 晋升或保留争议。
两者共享 Critic Notebook，但离线任务不能未经检验修改在线使用的正式记忆。可用相同基础模型和不同角色/任务配置，无需提前堆叠多个 Agent。

## 自主性边界
人工不筛选应当喜欢苏轼还是姜夔；只限定预算、权限、材料来源、证据标准、停止条件与回归评测。模型可自主决定阅读顺序、研究问题、保留哪些候选观点；「自圆其说」不是充分证据，须寻找反例、区分价值判断与可核验事实。文学评价可多标准并存，不强求单一排名。
「前人未研究」必须先做文献查新，不能以模型没见过为依据。允许无新见解、保留疑问或撤回问题。

## Bootstrap v0 实验
选苏轼、姜夔、吴文英及不同立场的原典、词话、论文；DeepSeek 推理模式优先用于自主提问、假说检验和记忆整理，常规阅读检索可用普通模式。先设小额成本上限（例如几十元，实际 token 预算待测），在独立脚本/隔离数据库运行，暂不接入线上写入。
基线：不带 Notebook 的同模型；对照：仅增加相同文献的 RAG；实验组：自主研究 + Notebook。固定未见作品测试集、不同 framing、隐藏作者、跨作品一致性与引用真实性；评估问题新颖性/价值、解释具体程度、反例处理和校准，不只看模型自评。保留运行日志、成本和研究轨迹。不能把新颖的表达直接当作新知识。

## 后续阶段
1. Critic Bootstrap：自主阅读与初始 Notebook。
2. Autonomous Research Loop：自主选题、Research Questions、周期性研究。
3. Critic Evaluation：独立评测、候选晋升、回归测试。
4. 产品候选：「Poeticus 正在思考」展示经核查的开放问题，允许读者提供线索但不直接改写公共审美记忆。

## 明确非目标
当前不做 RL / LoRA / 权重更新；不以蒸馏名义宣称完成模型训练；不默认 AI 的自评分数高于人类或独立证据；不将研究假说当作已实现能力；不打断当前首页开发。
