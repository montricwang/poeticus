# 汉典、萌典与教育部辞典：七词查询实验记录（2026-10）

> 根据 [#234 压缩前实测记录](../archive/issue-bodies-2026-10-21/234.md) 整理，不是当前生产 Tool 的服务等级报告。早期实验通过 TinyFish 查询网页/官方萌典 JSON，随后有 Windows 和 WSL 标准库 Python 的真实请求回执；不能把不同环境的成功率或网页返回直接合并为生产 SLA。

## 为什么查询成功仍可能答错

2026-10-12 以七个真实诗文词语比较汉典页面与萌典 `/a/{term}.json`，**两者均有 6/7 个整词查询成功**。这是网页/条目可获得率，**不是释义准确率，也不是两套独立语文学证据**。

| 词与诗句语境 | 当时检索观察 | 不可忽略的问题 |
| --- | --- | --- |
| 綢繆：《诗经》「绸缪牖户」 | 汉典与萌典均有不同语义/书证 | 汉典部分释义同源于教育部辞典，不能算两家独立投票 |
| 葳蕤：张九龄「兰叶春葳蕤」 | 有草木茂盛义，也有委顿/懒散等别义 | 《红楼梦》书证的语义不能搬到张九龄 |
| 觱篥：李颀听乐诗 | 有吹管乐器释义，及悲篥/篳篥别名 | 异名归一有用，但非完整古乐器考据 |
| 菡萏：李商隐「惟有绿荷红菡萏」 | 汉典着重「未开荷花」，萌典有「荷花别名」 | 义项粒度和古代字书区分需另核 |
| 闌干：岑参「瀚海阑干百丈冰」 | 纵横、栏杆、泪横流等义项并存 | 不能总解为「栏杆」 |
| 嬋娟：苏轼「千里共婵娟」 | 美人、姿态、月亮等义并存 | 必须结合该句选择「月」义，并保留原书证 |
| 䰒𩮰：晏几道「晴雪半消花䰒𩮰」 | 整词在两处未命中，单字汉典有别义 | 单字「马鬣」「同鬃」拼接会误注整词；[教育部《异体字字典》䰒](https://dict.variants.moe.edu.tw/dictView.jsp?ID=111157) 当时给出「朦胧不清楚」及晏词书证 |

资料来源和许可须分开：萌典有[正式 JSON API](https://www.moedict.tw/about.html)，可返回读音、义项、书证；历史记录注明 **API 协议 CC0 与所用辞典正文 CC BY-ND 3.0 TW 并不等同**。汉典[站点许可页](https://zdic.net/terms/)的笼统标注不自动涵盖每份字书引文；教育部《重编国语辞典修订本》与萌典部分内容同源。《异体字字典》为罕见字和字形来源提供互补，并非可替代普通多义词查询。

## 真实环境核查与边界

历史记录的最后一次 WSL 探针由用户在 PowerShell 运行 `wsl python3 ...`，实际得到：`葳蕤` 200/2 个义项、`嬋娟` 200/3 个义项、`䰒𩮰` 404。这证明当时 WSL 的**直接 JSON HTTP→原义项/书证解析**可行。此前 Windows Python 曾发生 SSL EOF，重试成功；个别站点通过提取服务返回 404 不等于原站不存在。**当时 Python 探针并没有进入 Poeticus 产品代码**。

2026-10-20 后的实际产品研究接入另见 [PR #369](https://github.com/montricwang/poeticus/pull/369)：Agent 本地可选 `lookup_moedict` 与 DeepSeek `web_search(source=zdic)`，不代表汉典官方 JSON API 或公众词条自动抓取已实现。最新启用状态以[工具架构](../architecture/langgraph.md)与[#234](https://github.com/montricwang/poeticus/issues/234) 为准。

**可迁移实验结论**：先取有来源的完整候选义项、书证和字形映射，再结合 `poem_id` /选区/全诗语境选义；有疑义时展示其他合理解释。测评要分开计算条目命中、义项正确、书证准确、来源独立性和网络降级，不根据单次 HTML 可达性设计全站抓取。
