# Poeticus Skill 设计原则

> **状态**：当前工作原则，依据 Poeticus 的开发与文学分析实验整理；不是外部权威标准，也不表示其中每项做法都已通过独立实验。遇到反例时应修订。
>
> **用途**：为可重复调用的分析、检索、研究和核验 Skill 提供共同约束。它规定设计时需要考虑什么，不要求所有 Skill 使用同一份提示词或输出格式。

## 核心判断

**Skill 应当教模型怎样完成一类工作，而不只是告诉模型应该知道什么、相信什么或怎样说话。**

一份 Skill 不必很长，但应当有明确职责、可追溯的依据、清楚的使用边界，以及能检验效果的案例。

## 六项共同原则

### 1. 明确任务和边界

说明 Skill 解决什么问题、何时使用、需要哪些输入、产出什么，以及哪些情况不适用。不要把多个无关职责塞进一个万能提示词，也不要为了形式完整而强制每个任务都调用它。

### 2. 让依据和判断可以追溯

重要判断应能回到原文、数据、工具结果或明确规则。至少区分：

- **来源明确陈述的内容**；
- **从材料中观察到的分析动作或现象**；
- **模型据此提出的解释或推断**；
- **经过独立案例检验的可迁移方法**。

引文能在原文中定位，只能证明引文位置正确，不能自动证明评论结论成立。文学材料还应保留作者、版本、年代和上下文；来源有争议时，不将其压成单一确定答案。

### 3. 分清材料、方法、立场和暂定观点

Poeticus 现有的四层分工继续适用：

- **Library** 保存原典、研究著作和其他材料，并记录出处与版本。
- **Skills** 保存可以重复执行的分析步骤、检索策略和核验方法。
- **Persona** 保存稳定的研究纪律，例如独立判断、尊重证据和承认不确定性；不直接照搬某位评论者的审美立场。
- **Notebook** 保存 Critic 自己提出的观点、反例、疑问和修订历史；模型先前说过的话不能冒充外部证据。

读过一本书不等于学会了其中的方法；生成一张方法卡也不等于已经得到可靠的 Skill。

### 4. 按工作性质分配职责

能够由代码稳定计算或校验的内容，优先交给代码；需要查证来源的内容，交给检索与文献工具；需要比较、解释和综合判断的内容，再交给模型。各环节应明确交接什么，避免让模型猜测本可查证的事实，也避免工具只返回材料、却被误当成已经完成解释。

### 5. 允许未知、争议和多种解释

Skill 不应为了让答案显得完整而强行定论。证据不足时可以保留问题；材料互相冲突时应展示冲突；某种方法不适用时应说明限制。古代批评家的概念和判断尤其需要保留历史语境，不能不经论证就升级为 Poeticus 的通用审美标准。

### 6. 用独立案例检验效果

不要只看 Skill 写得是否漂亮、模型是否声称自己学会了。验证时应尽量：

- 使用未参与提炼的作品或问题；
- 对照原有模型、只增加相同材料的版本，以及启用 Skill 的版本；
- 检查原文引用、论证步骤、反例处理和解释质量；
- 保留失败案例，并检查新版本有没有损害原有能力。

条件允许时固定模型、可用材料和工具预算。小样本只能支持有限结论；没有证明稳定收益的内容可以继续留在研究候选库，不必进入在线 Agent。正式启用的 Skill 应可版本化、可撤回。

## 文学研究中的材料怎样互补

不同来源可以教会模型不同的事情，不应混成同一种“知识”。

| 来源 | 主要贡献 | 不应直接推导出的结论 |
| --- | --- | --- |
| 《唐宋词鉴赏辞典》等现代赏析 | 从具体评论中观察细读、比较、组织证据和形成论证的做法 | 一条被模型标注的方法已经正确、独特或普遍有效 |
| 古代诗话、词话和文论 | 提供有历史出处的批评概念、评价标准、具体判断及其争议 | 古人的说法就是跨时代通用的规则 |
| 王兆鹏《词学研究方法十讲》等治学方法著作 | 提供比较、纵横、网罗、交叉等读书方法，以及目录调查、版本辨析、校勘、笺注、辑佚、辨伪、词人生平考订和作品系年等研究程序 | 文献考证方法本身就能决定作品的审美价值 |

三类材料可以互相补充。例如，研究一处用典时，治学方法帮助查找并核对出处；古代批评材料提供历史上的理解方式；现代赏析中的分析做法帮助模型比较文本细节、组织证据并解释其作用。实际调用顺序应由问题决定，不必每次机械地走完全部步骤。

**古代批评材料应当纳入研究范围，但要作为独立来源线索处理。** 它们可以先进入 Library，经过原文与历史语境核对后，再提炼出可执行的方法候选。只有经过实际作品检验的方法才适合成为正式 Skill；古人的具体观点应保留出处和立场，不自动写进 Persona。

王兆鹏的《词学研究方法十讲》（北京大学出版社，2008；[馆藏书目](https://opac.uibe.edu.cn/opac/book/379412c955839290cfde937a87fdc7cb)）可作为“如何做词学研究”的方法来源。它与现代赏析方法提炼并不重复：前者偏重如何查找、辨析和核验研究材料，后者偏重评论者如何分析作品并组织解释。若实际使用的是书名相近的其他版本或著作，应分别记录书名、版本和来源，不凭相似书名合并。

## 最低设计信息

每个 Skill 至少应让维护者看清以下内容，但不要求所有 Skill 按同一模板输出：

- 解决什么问题、何时调用；
- 需要哪些输入，产出怎样的结果；
- 关键操作与所依赖的证据；
- 适用边界、常见失败情况；
- 用哪些案例检验，当前证据支持什么结论。

详细程度按风险决定。简单的格式整理 Skill 不需要复杂评测框架；会影响文学判断、来源归属或事实结论的 Skill，则需要更严格的出处检查和独立案例验证。
