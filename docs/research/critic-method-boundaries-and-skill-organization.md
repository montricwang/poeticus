# 十四类批评方法的边界与 Skill 组织建议

状态：研究方案，尚未接入生产 Agent。本文先明确职责和组织方式；不自动合并类别，不把候选 Skill 写成已验证能力。

## 一、先区分分类标签与运行时 Skill

十四类标签混合了不同层级的东西，并非十四个天然互斥、同层级的能力：

- **观察对象**：`TEXT_WORD`、`PROSODY`、`IMAGE`。
- **组织与呈现方式**：`STRUCTURE`、`NARRATIVE`、`TIME_SPACE`。
- **文本关系与外部证据**：`ALLUSION`、`INTERTEXT`、`CONTEXT`、`HISTORY`。
- **解释与评价**：`ALLEGORY`、`AESTHETICS`。
- **跨类别的推理操作**：`COUNTERFACTUAL`、`DEBATE`。

因此，**数据标签可以保留十四类；运行时不应把十四类当作必须互斥、每次只能选一个的路由，也不应把 14 类 × 3 个篇幅版本当成 42 个独立 Skill。** 同一条分析可以有一个主类和若干辅助类，是否加载辅助能力由当前问题决定。

主类判断原则：看这条方法的核心问题是什么、主要证据是什么、最关键的推理动作是什么。辅助类只记录真正参与推理的第二种职责，不因出现某个词或意象就机械加标签。

## 二、十四类职责与边界

| 类别 | 首要问题 | 负责的工作 | 不应越界；何时交给相邻类别 |
|---|---|---|---|
| `TEXT_WORD` | 这个字、词、句法或旧语在此处怎样起作用？ | 词义、虚词作用范围、施受关系、主语歧义、句法、局部修辞与可检验的字词对照。 | 不能由一个字直接断定人物品性、作者身世或政治寄托。声律是关键依据时交 `PROSODY`；典源关系是关键时交 `ALLUSION`／`INTERTEXT`。 |
| `PROSODY` | 可验证的声律形式怎样参与意义组织？ | 韵脚、换韵、平仄、句逗、长短句、叠句、词谱与历史音韵条件。 | 不能把现代普通话、后出词谱或失传曲调当作宋代演唱的直接证据，也不能说声律必然决定情绪。若主要在释词义，主类仍是 `TEXT_WORD`。 |
| `IMAGE` | 作品具体呈现了哪些感官对象，它们怎样排列和相互作用？ | 色彩、明暗、声场、触嗅、动静、远近、视点、意象组合与感知转换。 | 意象出现是文本观察，不自动证明象征寄托或整体审美价值。由物象推导隐含指涉时交 `ALLEGORY`；解释艺术效果时可配 `AESTHETICS`。 |
| `STRUCTURE` | 作品各部分怎样组织、照应、转折并共同形成意义？ | 分段、篇眼、领字、铺叙、对照、照应、伏笔、复沓、开合与结尾回收。 | 不能只因发生了时空切换就把所有分析归为结构；须说明它对全篇组织的作用。人物如何看、说、行动归 `NARRATIVE`；时空关系本身归 `TIME_SPACE`。 |
| `NARRATIVE` | 谁在说、看或行动？词中情境如何展开？ | 发话者与受话者、观察位置、角色关系、动作、梦境、回忆、悬想、事件次序与动机推断。 | 文学角色不自动等于历史作者或真实亲友；先后不自动证明因果。事件发生顺序与写作呈现顺序要分别记录；时空坐标复杂时配 `TIME_SPACE`。 |
| `TIME_SPACE` | 词句怎样构造时间层次、空间关系与移动？ | 昼夜季节、今昔、梦醒、远近、内外、方位、行程线索、视点变化与时空叠合。 | 文学空间不自动等于真实地理，词内时标不自动确定创作年代。需要确认古迹、路线或事件时交 `HISTORY`／`CONTEXT`；时间跳接的叙述功能可配 `NARRATIVE`／`STRUCTURE`。 |
| `ALLUSION` | 这里是否使用了某个典故、旧语或文化故事？ | 找到候选典源、核实原义与来源层次，说明本篇如何沿用、缩写、变形或反用。 | 主题相似不等于用典，报出出处也不等于完成分析。若重点是跨作品的广泛比较或文本变形，交 `INTERTEXT`；若典源涉及可争议史实，再交 `HISTORY`。 |
| `INTERTEXT` | 当前作品与哪些其他文本形成可说明的关系？ | 原句并读、同题比较、唱和、化用、同作者互证、母题变化与接受史。 | 相似不自动证明直接影响、师承或作者意图。若核心任务是查明特定典故出处，优先 `ALLUSION`；若需要证明年代、作者或事件，交 `HISTORY`。 |
| `CONTEXT` | 哪些作品内外条件可能改变当前解释？ | 先界定问题，再选择题序、自述、体裁、社会风俗、器物、地理、作者其他作品等必要材料。 | `CONTEXT` 负责判断“需要什么背景、背景怎样关联词句”，不代表背景事实已被证实。涉及具体年代、行迹、制度或史事核验时交 `HISTORY`。 |
| `HISTORY` | 哪些历史、编年、人物或地理事实能够被独立核实？ | 史源分级、版本与转引链、系年、仕履、事件先后、古今地名、制度礼俗及传说辨伪。 | 史实相合不等于作者本意；无法证实作者意图时仍可保留一般性文学解释。它是 `CONTEXT` 中事实核验较强的专门能力，不应重复铺陈与问题无关的背景。 |
| `ALLEGORY` | 从字面景物或情境到隐含指涉，中间的解释桥梁是什么？ | 检查比兴、象征、寄托、物我对应及政治／身世读法；比较词面解释与隐含解释的增益、反例和替代读法。 | 不能把花鸟意象固定映射为某类人物，也不能因作者有某种经历就认定每首词都有寄托。它属于较高风险的解释推断，须配合 `IMAGE`、`TEXT_WORD` 或外证，而非取代它们。 |
| `AESTHETICS` | 具体写法怎样产生某种可说明的审美效果？ | 把“含蓄、清空、悲壮、雅俗”等评价拆成词句、形式、预期变化与读者效果之间的推理链。 | 不把风格标签当作论证，不把个人感受或评论家的标准升级成普遍法则。具体机制可由 `TEXT_WORD`、`IMAGE`、`STRUCTURE`、`PROSODY` 等提供；`AESTHETICS` 负责解释效果，不重做所有细读。 |
| `COUNTERFACTUAL` | 如果只改变一个写法变量，解释会发生什么变化？ | 对换字、删句、重排、不同结尾或替代读法作受控比较，说明实际差异与解释收益。 | 假设改写不是历史异文，也不能证明作者真的考虑过这个方案。它是跨类别的检验动作，常与 `TEXT_WORD`、`STRUCTURE`、`PROSODY` 或 `AESTHETICS` 配合，不必每次单独启动。 |
| `DEBATE` | 面对真实异说，哪一方的论据更能支撑结论？ | 公平重建事实、解释或评价之争，比较双方证据、前提、反例及结论强度。 | 不为展示辩论而编造对手；驳倒一条理由不等于证明相反说法。涉及具体文本或史实的争点，应调用相应主类能力；`DEBATE` 负责比较论证，不替代取证。 |

## 三、六组高频边界

### 1. `TEXT_WORD` × `PROSODY`

- 词义、句法、主语、动作和语气变化是核心证据：以 `TEXT_WORD` 为主。
- 韵脚、平仄、词谱或历史音韵是核心证据：以 `PROSODY` 为主。
- 一字既影响语义又关系协律时允许双标签；必须分别写出语义证据和声律证据，不能用“合律”自动证明“用字更佳”。

### 2. `ALLUSION` × `INTERTEXT`

- 先要查清典源、故事原义或典语来源：`ALLUSION` 为主。
- 重点是本词与另一文本的改写、回应、差异或关系网络：`INTERTEXT` 为主。
- 两者可以串联：先核源，再比较转化。文化联想、文本相似、明确化用和直接影响应分级表达。

### 3. `CONTEXT` × `HISTORY`

- `CONTEXT` 决定什么背景可能影响当前问题，并说明背景与词句的关联。
- `HISTORY` 核实背景中的具体事实、时间、地点、人物和史源。
- “找到一段背景资料”不等于历史核验完成；“史实存在”也不等于该史实就是作者写作意图。

### 4. `STRUCTURE` × `NARRATIVE` × `TIME_SPACE`

- `STRUCTURE`：段落／句群之间的关系与全篇组织。
- `NARRATIVE`：谁在说、谁在看、谁在行动，以及事件如何被讲述。
- `TIME_SPACE`：何时何地、视点怎样移动、不同时间与空间怎样并置。

同一个回忆段可以同时涉及三者，但输出要回答不同问题：回忆如何被讲出（`NARRATIVE`）、今昔空间怎样并置（`TIME_SPACE`）、它如何重释结尾或统摄全篇（`STRUCTURE`）。不要因为三个标签常共现就合并，也不要把同一段分析机械重复三遍。

### 5. `IMAGE` × `ALLEGORY` × `AESTHETICS`

按推理层级区分：

1. **看到了什么**：景物、声音、色彩、位置和物象关系（`IMAGE`）。
2. **写法产生什么效果**：反衬、节奏、留白、复合情绪等，并说明机制（`AESTHETICS`）。
3. **是否另有所指**：物象与人物、身世或政治事件之间是否有文本桥梁与独立旁证（`ALLEGORY`）。

后一层不能倒过来替前两层定调。即使寄托读法成立，也不必抹掉字面景物与审美作用。

### 6. `COUNTERFACTUAL` × `DEBATE`

- `COUNTERFACTUAL` 是受控比较：只改变一个主要变量，观察意义、语气或结构的差值。
- `DEBATE` 是论证评估：重建真实存在的不同主张，判断证据与推理是否足够。

反事实可以成为论证中的一项测试，但不能替代版本、史料或典源证据；两者也都不应成为每次分析的强制步骤。

## 四、建议的 Skill 组织方式

### 目标结构

当前生产代码的 `prompt_loader.py` 仍使用固定提示词，没有动态 Skill 注册／加载机制。以下是先用于文件组织与离线试验的目标结构，不表示生产 Agent 已具备自动路由和按需加载能力；是否接入生产运行时仍按 #311 的独立验收决定。

1. **共享核心规则（一个）**：来源与推断分层、引用可追溯、允许多解、按证据强度表达、工具结果不等于解释完成、证据不足时停止。公共规则只维护一份，不复制进十四份长提示词。
2. **紧凑路由索引（一个）**：十四类各用几行说明触发条件、主要输入、主类选择、交接对象与不应触发的情形。它负责“选哪个”，不负责展开全部分析步骤。
3. **标准版模块（十四个候选）**：作为每类的默认可执行内容，保留任务、触发条件、关键步骤、证据要求、停止条件和必要的交接说明。一次任务通常只加载一个主模块，确有需要时再加一两个辅助模块。
4. **详细参考（按类组织）**：保存子方法树、复杂例子、反例和疑难情况；只在问题复杂、标准流程无法解决或需要特定子方法时查阅，不默认全量塞进上下文。
5. **评测案例（独立维护）**：用于测试路由、边界和实际效果，不把长篇案例库复制进每个 Skill。

### 简洁版、标准版、详细版各自做什么

| 现有版本 | 建议职责 | 不应承担的职责 |
|---|---|---|
| 简洁版 | 路由卡／快速入口：说明何时用、核心动作和红线。 | 不作为与标准版完全独立的第三套运行规则；不承担全部子方法与案例。 |
| 标准版 | 默认模块：模型实际需要执行的流程、证据要求与停止条件。 | 不重复完整研究过程、全量记录统计或所有案例。 |
| 详细版 | 参考资料：疑难子方法、反例、历史争议与更完整的示范。 | 不默认加载；不能仅靠篇幅更长就声称效果更好。 |

三版可以不逐句对应，但关键规则、证据门槛和边界必须一致。来源统计、研究进度和审计状态优先留在研究 README／元数据中，不应成为运行时提示词的主要内容。

### 不同职责的组合规则

- `ALLUSION` 可作为 `INTERTEXT` 的专门入口；二者仍保留独立模块，因为典源核验与跨文本关系分析的输出目标不同。
- `HISTORY` 可作为 `CONTEXT` 的事实核验模块；不必每次加载。
- `DEBATE`、`COUNTERFACTUAL` 是按需启用的推理操作，不默认和每个主类捆绑。
- `IMAGE`、`TEXT_WORD` 等提供局部文本观察；`AESTHETICS`、`ALLEGORY` 属于在证据上继续形成解释的不同路径，不能把后者当成自动后处理。
- `STRUCTURE`、`NARRATIVE`、`TIME_SPACE` 可以联合使用，但各自只回答其职责内的问题，最终合并成一条不重复的论证。

## 五、验证方式与停止线

先做离线小试，不改生产 Agent。挑选 6–10 个问题，覆盖单类任务、上述边界组合、一个多类任务，以及证据不足或真实异说场景。固定模型、材料、可用工具和调用预算，比较：

- 不加载候选 Skill 的基线；
- 只加载共享核心规则；
- 加载一个相关标准版模块；
- 对确实需要的任务加载两个互补模块。

记录模型选了什么能力、是否多余加载、工具轨迹、引文与事实是否可靠、是否把推断说成事实、是否重复套话、是否保留合理异解。用实际失败解释结果，不以 Skill 文案长度或单一总分判断成功。小样本只用于发现明显的路由和职责问题，不能宣称十四类已整体验证。

**本轮验收目标**：十四类职责与主要边界有可执行定义；三版文件有明确分工；高频组合有交接规则；未决问题与证据不足有标记；不自动改写全部分类记录，不接入生产 Agent。剩余风险记录继续复核，并在出现足以改变边界定义的反例时更新本文。
