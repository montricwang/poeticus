探测方法与失效边界

这轮实际做了什么

  • 下载官方 Postman ZIP 与 Swagger OpenAPI，分别记录 SHA-256；逐例保留 71 条 Postman 输入变体。
  • 低频串行 GET / POST，只读数据或文本分析；每条响应最多读取 102,400 字节。
  • 保存方法、路径、运行时状态码、耗时、MIME、字段名与首个列表元素的形状。不持久化原始全文或访问凭据。
  • Swagger 补测中存在用于触发路径的临时参数；404、400 可能由无效输入引起。

这轮不能证明什么

  • HTTP 200 + JSON 结构，不说明该输入有真实、正确、完整的知识结果。
  • 较大的响应被主动截断，不能据此判断实际全量列表结构和记录数。
  • 单次计时包括网络环境差异，只用于定位慢接口，不能当成 SLA 或 p95。
  • 未测试高风险批量导出、登录会话或协议写调用；未测并不等于接口不存在。
  • 所有外部数据的权利状态均需独立确认，不能因公开访问而对外镜像。
