# Critic Skill 路由索引（离线试用稿）

状态：用于十四类边界审查与小规模离线试用；不是生产 Agent 的动态路由配置。当前生产代码尚无动态 Skill 注册／加载机制。

## 路由规则

1. 先识别用户真正要解决的问题，不因出现某个词、意象或历史人名就自动调用对应 Skill。
2. 选一个最能回答当前问题的**主类**；只有辅助类能补上必要证据或执行明确的验证动作时才添加。
3. `DEBATE` 与 `COUNTERFACTUAL` 是按需启用的推理操作，不是每次分析的必经步骤。
4. 先分清文本事实、来源陈述、模型推断和未核实猜想。需要外证时，应说明查证目标；工具结果本身不等于文学解释。
5. 一旦两个 Skill 会重复执行同一分析，保留主类的完整论证，把辅助类限制在它独有的工作上。

## 十四类快速选择表

| 主类 | 什么时候选 | 主要交付 | 典型交接 |
|---|---|---|---|
| `TEXT_WORD` | 关键在字义、句法、虚词、主语或局部修辞。 | 词句证据、语义／句法差异及其解释限度。 | 要检声律加 `PROSODY`；要做受控替换时加 `COUNTERFACTUAL`。 |
| `PROSODY` | 关键在韵脚、平仄、词谱、句逗或历史音韵。 | 可核的形式模式、所用音系／词谱依据、有限的声情解释。 | 字义是主问题时让 `TEXT_WORD` 主导；历史音证据不足则停止推断。 |
| `IMAGE` | 关键在景物、感官、视点、色彩、声场或意象组合。 | 明写细节、感知／构图关系及其文本作用。 | 解释审美效果加 `AESTHETICS`；提出隐含指涉才加 `ALLEGORY`。 |
| `STRUCTURE` | 关键在分段、篇眼、照应、转折、铺叙或结尾。 | 句群／段落关系与对全篇理解的影响。 | 角色和事件如何展开加 `NARRATIVE`；时空轴线本身加 `TIME_SPACE`。 |
| `NARRATIVE` | 关键在谁说、谁看、人物行动、梦境、回忆或悬想。 | 发话者／观察者、事件顺序、场景切换与推断边界。 | 时间和空间坐标复杂时加 `TIME_SPACE`；涉及真实生平时另查 `HISTORY`。 |
| `TIME_SPACE` | 关键在今昔、昼夜、远近、方位、移动或时空叠合。 | 明确时空线索及其组织关系，不擅自补全行程。 | 真实地点／年代要查 `HISTORY`；叙述功能可配 `NARRATIVE`／`STRUCTURE`。 |
| `ALLUSION` | 关键在确认特定典故、旧语、人物故事或文化出处。 | 候选典源、出处可靠度、原义与本篇转化。 | 比较更广泛的文本关系加 `INTERTEXT`；史事真实性另查 `HISTORY`。 |
| `INTERTEXT` | 关键在同题比较、唱和、化用、回应或文本间差异。 | 原文并读、相同／变异之处、关系强度与替代解释。 | 先确认典源时加 `ALLUSION`；不以相似性单独证明直接影响。 |
| `CONTEXT` | 关键在决定哪些背景会改变当前词句解释。 | 背景事实如何关联具体词句，以及哪些背景无助于解题。 | 需要核定年代、人物、地点或事件时交 `HISTORY`。 |
| `HISTORY` | 关键在作者、系年、行迹、历史事件、古地名、制度或史源。 | 来源链、可证事实、冲突与未决事项。 | `CONTEXT` 负责把已核背景接回词句；史实不自动证明作者本意。 |
| `ALLEGORY` | 关键在比兴、象征、寄托或字面之外的隐含指涉。 | 字面细节、解释桥梁、竞争读法、旁证需求与结论强度。 | 先由 `IMAGE`／`TEXT_WORD` 建立词面证据；具体政治／历史指认另查外证。 |
| `AESTHETICS` | 关键在解释“含蓄、悲壮、清空”等审美评价如何成立。 | “具体写法 → 作用机制 → 审美效果”的论证链。 | 由 `TEXT_WORD`、`IMAGE`、`STRUCTURE`、`PROSODY` 提供具体机制；不以风格标签代替细读。 |
| `COUNTERFACTUAL` | 关键在检验换字、删句、重排或替代解释造成的差别。 | 单变量改动、具体差值、适用条件与未排除解释。 | 必须与一个主问题绑定；假设改写不是历史异文。 |
| `DEBATE` | 存在真实的竞争解释、事实主张或评价标准之争。 | 双方主张、各自证据／前提、反例与结论强度。 | 根据争点调用相应专门能力；驳倒一方不等于自动证明另一方。 |

## 组合时只传递必要结果

- **用典链**：`ALLUSION` 核出处 → `INTERTEXT` 比较转化；只有涉及真实历史主张时再由 `HISTORY` 查证；`CONTEXT` 只整合会改变解释的背景。
- **时空链**：`NARRATIVE` 说明谁在回忆或悬想 → `TIME_SPACE` 标明时间／空间关系 → 仅当这一安排影响全篇组织时再由 `STRUCTURE` 说明作用。
- **意象链**：`IMAGE` 记录文本中可见的对象与关系 → 需要解释审美效果时调用 `AESTHETICS`；提出隐含指涉时另走 `ALLEGORY`，不能直接从意象跳到寓意。
- **争议链**：领域 Skill 先核事实和文本 → `DEBATE` 比较论证；`COUNTERFACTUAL` 只在能公平改变一个变量时作为补充测试。

## 离线试用记录

每次试用至少记下：问题、选定主类、辅助类及触发理由、未调用的相邻类及理由、使用的工具／证据、结论中的事实与推断、是否发生重复步骤或过度确定。不要只记录模型最终答得像不像专家。
