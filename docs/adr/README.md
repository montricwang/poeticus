# Architecture Decision Records

这个目录记录已经形成稳定系统边界、会长期影响维护方式的架构决策。

ADR 与 Decision Register 的分工：

- ADR：描述当前采用的架构方案、上下文、后果和被放弃的主要替代方案；
- Decision Register：保留证据强度、Origin、working default、open question 和重新审视条件；
- devlog：记录当天实际发生的过程。
