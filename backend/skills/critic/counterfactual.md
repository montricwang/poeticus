# COUNTERFACTUAL｜反事实比较 Skill

> Critic 日常默认版。依据《唐宋词鉴赏辞典》统一数据集里 COUNTERFACTUAL 的 200 条方法观察。原始引文锚点见本目录 source JSONL。**这些是既有结构化观察的再归纳，不能声称本轮已独立逐篇核验全文。**

## 职责与交接（边界协作修订）


- **主责**：为现有主问题做受控换字、删节、重排或替代读法测试。
- **何时作为主方法**：确有可公平改变的一个变量，且比较能区分解释时才调用。
- **不负责**：把假设改写冒充作者原稿或真实异文，也不为凑流程强制每首词做反事实。
- **需要协作时**：由 TEXT_WORD／STRUCTURE／PROSODY 等保持原来的分析主责；真实版本异文交 HISTORY 核证；不同主张的全面论证由 DEBATE 处理。
- **交接前的证据**：明确实际词句、只改变一个主要变量及真实差值；如果替代项根本不合律要指出。
- **易错边界**：删去一句后结构变化可说明此句必要性；不能证明作者真的考虑过删句版本。

以最能解决用户当前疑问的一类为主，只有辅助分析能提供新证据或完成不同的推理动作时才加一类；原始分类标签不代表必须加载一个独立 Skill。

## 目的

利用**可撤销的替代假设**，说明词人实际表达为什么产生某种效果。批评者构造的「如果换写……」与作品人物自己的「纵使、若使、愿……」是不同对象：前者考察形式和叙事差值，后者阐释人物不可能的愿望与条件。

## 通用步骤

1. **观察**：提取完整承重句及上下文，分开词作、赏析引文与模型归纳。标记否定、条件、语序、意象、篇章位置。
2. **实验**：找到可比较的替代项，并说明它是研究者假设、已有异文、别篇写法、一般常情还是词中虚拟。
3. **控制**：尽量一次只改变一个变量；若改动会牵动词律、典故或篇幅，应把这些影响列出来。
4. **比较**：点明具体变化：声情和速度、动作方向、主动者、时间次序、画面疏密、情绪反跌或结句余味。
5. **解释**：连接差异与词中情感/篇章功能，避免从艺术形式直接跳到作者真实心理、生平或政治意图。
6. **反证**：找能使另一种解释同样成立的文本，检查常情预期是不是未经证明的偏见。
7. **定级**：逐项区分「原文支持」「暂定归纳」「存在争议」「尚待核验」。如果实验没有稳定差值，不要硬做。

## 12 类初步动作

| 子方法 | 动手做什么 | 关键限制 |
|---|---|---|
| 替字与近义改写 | 替换承重字，比较语气、声韵、动静、视角 | 不拿破律或拙劣的候选词证明原字无可替 |
| 语序与施事转换 | 恢复平直句序，比较谁行动、先见什么 | 须顾及词调、倒装习惯 |
| 删、补、穿插 | 假设删去景物、补直白结尾或取消穿插 | 不得从部分损失推断意义归零 |
| 题材惯例翻转 | 先建立节日、春景或送别的阅读预期，再看偏离 | 惯例不是所有作品必须遵守的规律 |
| 不可能愿望 | 解析未成立的条件与愿望落空 | 不将修辞想象说成历史事实 |
| 否定备选解释 | 用文本反问更直白的归因是否充分 | 排除 A 不能证明 B |
| 替代情景/结局 | 构造另一种可读的写景或叙事走向 | 替代方案不是作者底稿 |
| 反向条件比较 | 人与物、此与彼的能与不能做同维对照 | 不宜从自然现象直接推出历史因果 |
| 现实常识反查 | 以小序、物候、距离或史实检验字面读法 | 应先核版本与时空，也可能是倒叙 |
| 异文/前文本对照 | 对齐实际版本，比较声口与寓意差值 | 艺术评价不能决定底本真伪 |
| 并列本事假设 | 保留两种故事情境，抽取词内共同可证部分 | 可能故事不能当发生过的事实 |
| 反语与价值逆转 | 对比字面旷达/责备与现实处境 | 不把一切闲适都政治悲愤化 |

以上是**工作类目**，并非固定文学理论分类；某条可与互文、叙事、细读等 Skill 交叉，但日常分析只调用当下最有解释力的动作。

## 五个重要范例

**控制词义（0060:m1、0131:m0）**：比较「咽」与「断、滑、涩、远」，「菡萏香销翠叶残」与「荷瓣香销荷叶残」。判断什么语义、声韵、联想真的有差别，而非简单判好坏。

**章法检验（0251:m3、0478:m1）**：在点题与景句间虚插词句，或把「花褪」「柳绵吹少」连续排列而不用燕子、绿水穿插，看情绪、疏密、段落呼吸如何变化。

**现实约束（0453:m1、0623:m4）**：检查雨具先去与「一蓑」、金陵至采石的听觉距离。但现实不合并不能直接证明唯一象征，须考虑夸张、梦境和时序。

**故事空白（0288:m3、0398:m5）**：听歌新动心或原已闻名；秋千架唤起旧事或仅为散愁。无外证时不要替评论者或词人敲定本事。

**反证失败（0313:m5、1206:m1）**：认为显达词人不可能遭遇男女别离，或悼亡者必须赶到墓前，从而硬推政治寄托，都属于待反证的推理，不是可教给 Agent 的肯定规则。

## 输出协议

回答围绕：**原句与版本 → 比较变量与性质 → 实际差值 → 解释与支持它的证据 → 不能排除的其他解释**。需考据时先调用来源工具；没有差异时停止，不强迫套用。Skills 指导阅读行动，不强制得出预设审美结论。
