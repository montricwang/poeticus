# AESTHETICS｜词作审美机制分析

> 作用：把“含蓄、清空、艳而不俗、沉郁、豪健”等感受性判断追溯为能够指出句子、检验推论、允许异说的分析过程。输入可以是一首词或一个具体审美问题；不要求所有作品都套用同一套风格词。此为研究草稿，不代表评论者的原文规范，也不是 Poeticus 已发布的 Skill。

## 职责与交接（边界协作修订）


- **主责**：解释可观察的写法怎样形成含蓄、清空、悲壮、雅俗等审美效果。
- **何时作为主方法**：要评价具体艺术效果而不只是释义、描述画面或确认史实时。
- **不负责**：先给风格标签后找佐证，或把个人好恶当普遍美学法则。
- **需要协作时**：词义机制由 TEXT_WORD 提供；声律由 PROSODY、感官构图由 IMAGE、全篇安排由 STRUCTURE 提供；若评价延伸为隐含政治指涉，交 ALLEGORY。
- **交接前的证据**：用“文本细节→差异或预期→效果”的推理链，并允许同一写法有不同读者效果。
- **易错边界**：“含蓄”不是仅有省略，“豪放”也不等于声音必高昂；可比较不同评论者的评价标准。

以最能解决用户当前疑问的一类为主，只有辅助分析能提供新证据或完成不同的推理动作时才加一类；原始分类标签不代表必须加载一个独立 Skill。

## 默认分析路径

1. **先找现象，不先贴标签。** 记下最不寻常的语词、景物次序、构图、人物动作、声音、情绪转折、缺席的信息或收束方式。引出“为什么在这里这样写？”的局部问题。若已见旧评，先把它当待检假说。
2. **建立证据范围。** 至少引用相关原词句，标明所在片、前后句与说话者；如借词论、他作、创作时代，另注明来源与能支持的命题。词中景象、评论者阐释、模型补出的心理故事不可混写。
3. **把中介机制说出来。** 按“可观察写法 → 阅读中发生的注意/期待/对比 → 可能形成的情绪或意味”说明推断。只说“情景交融”或“语淡情深”而不说哪个字使景物带情，尚未完成分析。
4. **检验读法的竞争。** 可以作字面叙述、惯常题材表达、具体寄托或广泛人生共鸣等多种解释；比较哪一种更能覆盖全词，哪一环需要外证，哪些审美差异只是阅读偏好。
5. **按证据强度收束。** 将结果分为：词句可核对的形式事实、从上下文成立的审美解释、沿既有词论作出的评价、需要独立材料的作者意图/政治生平/文化史断言。最后一个层次不应借审美术语直接越级确定。

## 可调用的分析动作

| 何时注意 | 实际操作 | 不应越过的边界 |
| --- | --- | --- |
| 只写景、侧写、欲言又止 | 标出未写出的情语及可供读者补全的线索；比较“说破”是否改变余味（`0025:m3`、`0137:m3`） | 读者补全不等于事实性情节或唯一作者意图 |
| 美景与悲情、直语与曲意并存 | 将表层景色、人物处境、句法语气分栏；检查反差是反衬、并存还是反讽（`0119:m3`、`0308:m4`） | 反差未必就是讽刺或必然悲哀 |
| 景物好像有人的感觉 | 追踪人格化动词、抒情主体和视角转换，解释情感怎样从人移到物（`0036:m1`、`0359:m3`） | 有我/无我不是一贴即中的万能标签 |
| 画面寥寥数笔却引起丰富想象 | 清点作者写明和留下空白的部分，比较可能的补全路径（`0236:m1`、`1507:m1`） | “不写”本身不是美学成功的充分条件 |
| 意象或实物承载更大情理 | 先确立实物属性、在篇中如何重复/变换，再解释象征与人生联想的增量（`0012:m1`、`0548:m4`） | 意象可兼具实景和隐喻，勿将开放性压成唯一政治暗码 |
| 上下片、换头、结句改变强度 | 做逐句的情绪/材料时序表，解释铺垫、反转、迟到的点情与尾句停顿（`0107:m3`、`1500:m5`） | 结构规整与“高妙”属于两个不同判断 |
| 声响、词调、韵脚、语势突出 | 分清文字节奏、词谱格律与历史演唱；定位声调转折和词意关系（`0309:m3`、`1102:m1`） | 未核词谱与当时演唱时，不宣称实闻音效 |
| 一首词既俗又雅、既艳又悲 | 拆成语体、用典、形象密度、抒情强度、说话姿态等可比维度（`0288:m4`、`1509:m6`） | 雅俗/豪婉不能单由作者身份或题材决定 |
| 评论引用王国维、陈廷焯等旧评 | 先说该理论判准是什么，再指出此篇哪些词句真正满足或挑战它（`0107:m3`、`1053:m5`） | 古人评语不是自动正确的“证明”；不同批评标准可能冲突 |
| 作品使人共鸣或有宏大价值 | 分开可观察的叙述效果、可能的读者感发、伦理与文学史延展（`0319:m4`、`0166:m3`） | 单篇文本不证明全体读者体验、作者人格或时代定论 |

## 证据与回答要求

- **最小论证单元**：`词句／可观察特征 → 局部关系或相邻对照 → 解释效应 → 可替代读法或适用边界`。必要时补作者、版本、词谱或同题作品的证据，不必逢例全部查遍。
- **可表达不确定性**：例如“这句允许读作……，但仅凭此不足断定……”。宁可收窄结论，也不靠笼统名词装作已经证明。
- **输出自由**：针对问题挑选一至三种最有解释力的动作；诗歌允许兼具直白与含蓄、俗与雅、健与婉，不必择一。没有充分证据时不要硬给风格评价。
- **来源纪律**：本候选 Skill 从《唐宋词鉴赏辞典》AESTHETICS 方法观察初编而来；本文记录编号指向私有研究数据，不代替原词、原评论完整核对。
