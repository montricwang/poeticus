# IMAGE｜意象与感官分析 Skill

## 职责与交接（边界协作修订）


- **主责**：辨明色、声、光、味、触感、动静、远近和物象组合，先回答作品实际呈现了什么。
- **何时作为主方法**：景物关系或感官组织本身是问题核心时。
- **不负责**：直接给梅花、柳枝、风雨分配政治角色，也不负责全部审美优劣和作者心理史。
- **需要协作时**：意象的具体象征指涉交 ALLEGORY；审美体验的机制交 AESTHETICS；多层时空视点归 TIME_SPACE，若只分析景物的感知结构仍由 IMAGE 主导。
- **交接前的证据**：分清可见、可闻与评论者补画的镜头；“落花”不是自动等于伤春。
- **易错边界**：夜雨里“见柳丝”可能是听觉联想而非实际目见；“泪花”不证明有人流泪。

以最能解决用户当前疑问的一类为主，只有辅助分析能提供新证据或完成不同的推理动作时才加一类；原始分类标签不代表必须加载一个独立 Skill。

## 1. 职责与触发条件

Critic 遇到“为什么这几句景物有力量”“词如何以声、色、动静写人”“同一意象如何推进全词”“诗中有画意味着什么”等问题时，使用本方法研究词里的**可感知对象及其组织方式**。此 Skill 教会模型怎样观察、比对、推论；不预设它必须读出怀人、失意或亡国。

本类的来源是《唐宋词鉴赏辞典》2016 年版 548 篇赏析所关联的 **560 条 IMAGE 方法记录**。每条保留原始记录 ID、原赏析短引和位置；初步子方法与本目录 `image-taxonomy.json`、`image-coding.jsonl` 对应。91 条案例进一步进行了方法辨析，其余以原方法卡为基础进行结构化初编；这些不能等同逐篇精读或全部论证获得验证。

与相邻能力的分工：辨精确词义时结合 TEXT_WORD；论全篇布局时结合 STRUCTURE；涉及典源时调 ALLUSION/INTERTEXT；由物象推政治事件或人物真实经历时转 HISTORY/CONTEXT；“美”“境界”等审美评价须另有 AESTHETICS 的论证，不能以图像漂亮自动推出艺术成就。

## 2. 分析前的四个确认

- **文本现场**：列出最必要的原词片段及物象，不把赏析者的改写或模型想象当作词句。
- **观看/感受者**：是否有人在看、听、闻、触？视点、光线、声源、时间是否允许某种直接感知？如果只能从声音或痕迹想见，要直说“推知”“联想”。
- **内部关系**：单个物象的词典式寓意往往不足。找出红与绿、声与静、双与独、动与不动、此前与此后的关系。
- **解释目标**：本次究竟是在解释一句的鲜明效果、一段的叙事转场、人物未说出的心理，还是评论者的跨媒介观察？只选择相关操作。

## 3. 可按需调用的分析动作

### A. 重建感官与构图

**色彩/光影**：标出所写颜色、明暗、冷暖与参照背景，再问颜色关系造成什么效果。例 `0013:m0` 将日、花、水拆为同色增亮与异色相衬；`1190:m3` 检查柳色如何延续到人物春衫。不用“红必喜、白必悲”。

**声场与通感**：先确认声源、音量、远近与听者，再区分“声音使环境更热闹”或“正因除此再无别声而显静”。例 `0132:m0` 的蟋蟀鸣与寂静、`0033:m0` 的暗夜春雨听觉与柳丝视觉、`0093:m0` 的湖夜视听嗅觉组合。感官并列不一定是通感，听见的景也未必真实可见。

**空间/视点**：说明取景从哪里开始、是否被帘幕遮挡、景别由远到近还是局部反衬整体。例 `0052:m1` 由庭院进入帘后闺室，`0087:m0` 以“隔”保留美感距离，`0178:m1` 用一点山影衬湖面广大。只有文本有景序才说“镜头移动”，不能因景色优美泛称“电影感”。

**运动/静止**：先寻找真的运动物体、静止背景及观察者自身移动。例 `0221:m2` 中移动的是舟，山“来迎”可由相对运动解释；`1492:m1` 用怒浪与砥柱一峰形成强动与强静的反差。

### B. 解释物象与情感如何相接

**对举和反衬**：把两个对象差异写清，再说人物情绪。例 `0368:m2` 的燕归/人未归、`0223:m1` 的月圆/人离、`0862:m3` 的昔日春水/今日空殿。出现燕、花、月本身并不证明思妇或家国情怀。

**意象序列**：按原词顺序追踪景象变化，观察同一物象是否因时点、地点、关注者改变而变义。例 `0290:m2` 同样的花月先后承担往昔、受阻与愿望三种功能；`1280:m0` 六景横跨时间与城市，不应硬读作同一日连续事件。

**拟人和移情**：分清物的自然行为与赋予它的人类态度，再问词内哪一处显示情绪是投射。例 `0680:m1` 的画舸被迁怒、`0531:m2` 的山川仿佛有待、`1325:m1` 的雨中花形被读作眼泪。花“哭”不等于有人在现实中哭。

**情绪物化/象征**：找出形、重、色、流动、缠绕等具体属性怎样对应抽象感情。例 `0567:m4` 将离恨如砖石“砌”出重量，`0761:m0` 让游丝喻情缘、飞絮喻行人，两物不能含混成一个标签。必须说明“由哪个可见特征推出哪项解释”。

**侧写人物/缺席**：没有写人物时检查可见的物件、动作或余声。例 `0088:m1` 的织机声使织者间接在场，`1500:m1` 的酒冷、灯青暗示停杯与夜深。不可进一步填补未曾明说的身世情节。

### C. 保留观察的不确定性

评论者的“像画”“像电影”“色彩感”是解释语言，不能代替词句、原典和历史证据。感知需要光线和视点：`0033:m0` 暗夜柳丝可能是听雨后内在意象；`0351:m4` “青山缺”至少允许两种可行画面；`1505:m1` 可借洞穴与松啸“听知”不可见的风。遇到这类情况，**提出一个符合文本的解释即可，除非有排他证据，不必捏造唯一现场。**

## 4. 从观察到解释的最低证据链

建议按这五个问题作内部检查：

1. 具体词句写出了哪些声色形动？哪些是评论者增补？
2. 它们在空间、时间或感官上构成何种**关系**？
3. 哪个差异、缺席或转折使它不只是普通背景？
4. 该关系具体解释了哪个人物、语气、情绪或段落效果？
5. 若不用这一象征意义、换一个观察者或调换景序，解释是否仍可成立？

最终回答应是针对作品的自然论述，而不是机械地列出五步或十三类名称。证据薄弱时使用“可理解为”“评论者认为”，标出竞争读法和出处。

## 5. 不应犯的错误

- 从“落花”“杜鹃”“月圆”“双燕”直接得出固定情绪，不回查作品中人物和事件。
- 把“暗夜看不见”的猜测当成客观画面事实，或把视觉想象说成目击。
- 把评论者的诗画/电影类比当成诗人有摄影意识或古代画论铁律。
- 因同篇同时有声、色、香而强称通感；因两个景并列而强称反衬。
- 用审美评价句掩盖中间推理，如“色彩鲜明，所以境界高”。

## 6. 证据与接入边界

每条 IMAGE 的出处及 `evidence_refs` 参照 `image-source.jsonl` 中的段落、字符位置与 SHA256。抽取的 **1760 处评论短引中有 1750 处通过 EPUB 原段 SHA 与偏移量双重验证**；另外 10 处涉及 4 条记录，虽都在对应 EPUB 文件找到同一短引，却仍有段落哈希/位置差异。详情在 `evidence-verification.json` 与 `evidence-discrepancies.json`。

短引核实只证明**评论原书中确有这些文字**，并不自动核实上一轮方法卡对评论者意图的转述。输出时应区分原赏析短引、先前 AI 方法归纳与本轮 Skill 提出的可迁移动作。正式并入 Critic Skills 前，先抽查疑难样本及其他 Skill 的职责重叠，做少量真实词句的使用回归。
