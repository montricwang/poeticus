# TIME_SPACE｜词作时空分析

> **性质**：Poeticus Critic 候选 Skill；适用于解释词中景象如何按时间、位置、记忆与想象被安排，而不是替作者补写行程或心理史。根据《唐宋词鉴赏辞典》TIME_SPACE 401 条结构化方法观察（42 条定向再精析）编制，尚非逐篇原评通读后的定稿。
>
> **核心任务**：先确定“何时、何地、由谁看见或想到”，再问这些安排怎样推进理解；任何时间、地点、心理和历史判断都必须标明其依据层级。

## 职责与交接（边界协作修订）


- **主责**：标明时刻、季节、今昔、远近、方位与视点移动之间的关系。
- **何时作为主方法**：时间推进、地点转换、路线遮挡或虚实空间叠合确实改变解读时。
- **不负责**：把并列画面编成同一天行程，或由词内物候独断真实作年与地理。
- **需要协作时**：讲述者与事件视角交 NARRATIVE；转折对全篇的组织作用交 STRUCTURE；具体地名及时代条件交 HISTORY；感官构图可与 IMAGE 协作。
- **交接前的证据**：区分文本呈现顺序、想象时间与实地可见条件；不足时保持“位置未定”。
- **易错边界**：“斜照”可能是朝阳而非定是夕阳；梦中远行并不等于作者实历。

以最能解决用户当前疑问的一类为主，只有辅助分析能提供新证据或完成不同的推理动作时才加一类；原始分类标签不代表必须加载一个独立 Skill。

## 触发与停止

适用：词中出现时刻、季节、地名、登临/行旅、内外远近、梦与回忆、今昔重复或明显的视点跳切；也适用于读者问“为什么一会儿写春一会儿写秋”“人此刻究竟在哪里”“这一景是否真的看得见”。

不宜启动为独立主方法：作品几乎没有有意义的时空组织线索；读者问的只是词义或格律；已发现所涉“史实地点”只是典故或泛称而无须实地图证。可以指出资料不足，不强用框架。

## 分析流程

1. **抽取可检验的标志，不急着讲情感**。标时：日暮、残月、漏刻、斜照、春尽、年年、当时、明日；标地：楼、窗、渡口、江、山、古城、归路；标动作与感觉：起、望、闻、行、忆、想、梦、回首。把原词短引与本句位置对应起来。区分词中意象和赏析者为解释补出的句子。
2. **制作两张最小图**。时间表分清作品呈现顺序与所述事件的先后；空间表标出观察点、视野、路线、遮挡、可达与不可达。必要时用“当前／往昔／将来／梦中／纯想象”给每一幕标注状态。宁可留“未知”，不要把并列景象自动排成一日。
3. **选择真正发挥作用的机制**，而非把 14 个标签都走一遍。清楚的连续线索用显性时序与省略复原；记、当时、又见、想见与梦醒等用时间折返；内外、俯仰和远近用视点推移；路线、地理与阻隔需做现实条件核对；物候、漏刻、钟声、香尽等可作时钟；故都与遗迹要将历史层同眼前层分开；同地不同人用今昔异感；一室/万里与一日/数年并列用尺度耦合。
4. **提出可追溯的解释链**：具体词句 → 可观察时空关系 → 叙述或感知效果 → 有限的情绪／主题解释。例如两种感官同时失去远行者踪迹，可支持“离去距离逐渐增长”，但“目送者整夜守候”需另外证明（0112:m0）。若远景靠后文“独倚楼”才确定视点，应主动用后句校正前句，而不是抢先认定（0244:m2）。
5. **做至少一次反读**。测试时间链是否也可能是并列片段；远景是否只是回忆、想象或典故；自然周期是否被误作人事必然；地名是否泛称、借代或实地；情绪是否由其他写法解释。冲突无法排除时，保持两种解释并说明判断条件。
6. **回答读者而不是展示图表**。只写对理解真正起作用的 1–3 个关键切换，引用支持该步的短句，交代最重要的不确定处。

## 子方法速查

| 问题 | 候选操作 | 典型锚点与限制 |
| --- | --- | --- |
| 时间怎样流过、哪段被省略？ | 排列动作、声光、物候；标明断点 | 0034:m0、0398:m2：多线索可定大致时段，不定精确时刻 |
| 是旧景、眼前景还是想象的下一幕？ | 依领字区分时态与虚实，再比较两种顺序 | 0235:m0、0257:m3、0644:m0：预演的未来不是既成事实 |
| 读者跟谁看，从哪儿看？ | 定位视点，列可见、被遮、倒映、听见 | 0244:m2、1013:m1：不能中途无证更换观察参照系 |
| 有行程或空间难题？ | 核地名方位、道路／航线与实际可视条件 | 0071:m2、0507:m1、0915:m1：直线可见与道路可达不同 |
| 今昔何以同时出现？ | 固定不变地点，比变化的人／关系／政局 | 0551:m2、0864:m1：外部史实另行查证 |
| 物象为何使时间变得可感？ | 比较自然周期与人的等待、花期与寿命 | 0324:m1、0395:m2、1424:m4：循环不强制人事重现 |
| 情绪的“久”“远”如何被写出？ | 比较客观时长／距离与主观体验 | 0103:m3、0284:m0：心理远近不等于地理远近 |
| 室内外和虚实怎样扩缩？ | 按门窗、水镜、梦境重排观看层次 | 0322:m1、0653:m0：视线移动不等于身体走动 |

候选子方法包括 time-sequence、time-fold、viewpoint-sequence、journey-route、distance-barrier、sensory-clock、season-cycle、same-place-difference、historical-layer、imagined-space、time-experience、scale-coupling、spatial-geography、inside-outside。它们是可并用的动作，不是排斥性的主题格。

## 证据纪律与回答格式

- **一级**：词句可直接核见的时刻、方位、动词、视听标志。**二级**：从多项线索重建的视点、顺序与尺度。**三级**：人物意图、身世、历史影射、某年某地等外推。三级须注明“可能”“有评论如此理解”，需要时检索史料。
- 引用评论家观点时标明是其判断；将批评动作改写为通用方法时标明是 Critic 的提炼。只有结构化引文锚点而未核原赏析段时，不写“评论家已证实”。
- 写成“观察：…；时空关系：…；由此较有把握可说：…；仍不能确定：…”即可；不要求固定排版，不因美化表达而掩盖不确定。

**反例优先**：0462:m2（斜光也可能是晨光）；0799:m3（月夜和白日观雨未必是同一天）；1116:m4（方向排除不等于确定恋人身份）；1313:m4（后代把遗迹附会到另一地，不等于真实历史）；0253:m1（月霜不能无外证定深秋下旬）。

**层级位置**：本 Skill 只提供分析操作。可查文献与地理证据归 Library；一次作品判断及其反证归 Notebook；审美取向不从词典评论者自动搬入 Persona。
