# ALLUSION｜用典分析 Skill

**职责**：帮助 Critic 在已获得或能够检索词句证据时，识别典故如何构成文学论证，而非只做典故词典。根据本目录 539 条 ALLUSION 观察形成；所有个案先作为研究线索。此 Skill 不替代 Library 的古籍来源核验，不把评论者见解写入 Persona 或 Notebook 的既定判断。

## 职责与交接（边界协作修订）


- **主责**：定位具体典语／人物／旧故事，核典源并说明原义怎样在本篇被选用或反用。
- **何时作为主方法**：一句话必须依赖某典故、旧语、专名或故事背景才能准确读懂时。
- **不负责**：把主题相似判直接取法，或据典中人物推作者生平和历史事件。
- **需要协作时**：广泛同题文本的表达差异交 INTERTEXT；典籍中事件的真实性与系年交 HISTORY；隐含政治寄托由 ALLEGORY 检验，不由用典自动证明。
- **交接前的证据**：写明触发词、候选源文和关系强度；找不到唯一典源时不硬定。
- **易错边界**：“燕然未勒”先确认窦宪典与后世语用；要证明某词沿袭某位词人的写法则另用 INTERTEXT。

以最能解决用户当前疑问的一类为主，只有辅助分析能提供新证据或完成不同的推理动作时才加一类；原始分类标签不代表必须加载一个独立 Skill。

## 一、什么时候启用

作品出现难解专名、官服器物、仙佛神怪、历史人物、看似引自古文的固定措辞，或评论者用旧典解释新词的句义、人物、历史与写法时启用。纯粹的画面细读优先交给词句/意象分析；只需比较两篇文本表现技巧时，优先 INTERTEXT；需要独立证明系年、人物和历史事实时，联合 HISTORY，不能以本 Skill 代替考据。

不应假定任何陌生词都必有唯一典源。对一般惯用义与本篇没有独特对应关系的词语，可以止于语义解释。

## 二、工作流程

1. **先观察，不抢结论**。抄出作品中的触发字词及其上下两句，记录它是人物、故事、地名、器物、旧句、意象还是复合典语。独立描述无须典故即可成立的字面意义。
2. **建立候选典源**。从 Library 或可靠古籍检索候选。记录出处、版本、原句/最小情节、成书或使用年代；把原典、后世典语习惯、轶闻和近人赏析分开。若检索不到，承认未知。
3. **分解用典动作**。按证据选择最贴切的一种或几种操作：
   - **指称解释**：旧名物/制度/地名让一句话可读（`0007:m0`）。
   - **故事压缩**：触发字激活某个人物行动关系（`0012:m0`、`0016:m3`）。
   - **语义激活**：传统意绪解释当前行为的必要条件，而非直接认定现实经历（`0245:m3`）。
   - **借句变形**：逐字比照前后文本的保留、改动及功能变化（`0104:m3`）。
   - **逆用与改判**：读懂旧典常规含义，才能看见新作的否定、反衬或伦理重新排序（`0504:m1`、`1203:m1`）。
   - **多典分工**：分别定位每个典故的职责，考察其互补/冲突/递进关系（`0672:m2`、`1078:m3`、`1247:m3`）。
   - **历史与象征映照**：说明可比的处境、人格或历史记忆；把诗中声口与实际作者经历拆开（`0746:m1`、`0971:m4`）。
4. **完成从观察到解释的证据链**。至少写明：文本中有什么 → 原典确实包含什么 → 本词继承/改变了什么 → 因此能解释哪些具体字词、结构或情绪。用“如果没有这项典故，解释损失了什么”检查是否只是装饰性引经。
5. **寻找反例并收束**。检验：有无另一出处？是否只是通用文化套语？原文是否实际上反其意而用？当事者的性别、身份、时代、历史是否另有证据？若不满足，则改为“可能唤起”“可作类比”，不说“必然取自”“证明作者”。

## 三、证据要求

- 对**典源确证**：需有可复查的古籍/诗句、可定位的文本触发点，且时间方向不矛盾。
- 对**意义解释**：还需证明当前作品上下文为何选择该义；原典与本篇相似不能替代句内论证。
- 对**直接影响、人物本事、系年、政治寄托**：需要额外的独立材料；单靠典故不能升格为事实。
- 引文、来源位置、解释者和 AI 归纳各自标明。不要把上一轮 AI 的 `argument_path` 当作赏析作者逐字原话。

## 四、推荐的答题组织

尽量自然写成连续论述而不是固定表格：先提出与本词有关的问题，指出触发句与最必要的原典，展示关键差异，说明它如何改变解读，最后留出确切可知与尚有争议的边界。复杂或多典情况可分项标出证据等级。

**停止条件**：继续找典故已不能增强对这首词的解释，或证据不足以区分不同解释时，停止扩充。Skill 允许只解一个典语，不要求每首词都穷举其所有典故。

## 五、需要特别防范的误用

- 把失国鸟、屈原香草等传统象征直接断定为作者的政治立场；
- 因贾谊、庾信等人物处境近似，直接推断真实被谪对象与写作年代；
- 把两个传说混成一个故事，或把若干典故均解释为同一笼统“忧愁”；
- 把作品对古典材料的反转误写成忠实援引；
- 用典故数量、征引名家的权威感代替作品细读。

**研究边界**：所列方法依据结构化观察提炼，典源仍须在具体分析时独立核验。
