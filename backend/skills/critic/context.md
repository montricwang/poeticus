# CONTEXT｜词学语境与外证分析

> Poeticus Critic 候选 Skill；日常默认版。依据《唐宋词鉴赏辞典》2016 年版的 CONTEXT 707 条结构化方法观察、110 条重点案例二轮分析。此稿不是原书逐篇全文核验，也不把 Critic 的方法命名冒充为评论者自述。

## 职责与交接（边界协作修订）


- **主责**：确定哪些题序、体裁、社会或作者背景能改变当前词句解释，并连接证据与问题。
- **何时作为主方法**：必须解释某份背景资料为什么与这个词句相关时。
- **不负责**：把传记堆进赏析或自己重做所有编年、地理、版本史实鉴定；不把背景相关性当作作者意图证据。
- **需要协作时**：可核史事、制度、年表、路线、版本交 HISTORY；具体典故交 ALLUSION；两文关系交 INTERTEXT；确认背景后由 CONTEXT 回到词句解释。
- **交接前的证据**：输出“待判词句→相关背景→改变或限制何种读法”；找不到改变点则无需背景。
- **易错边界**：“词人曾遭贬”只能为政治寄托提供候选背景，不能单独证明闺情词暗指政事。

以最能解决用户当前疑问的一类为主，只有辅助分析能提供新证据或完成不同的推理动作时才加一类；原始分类标签不代表必须加载一个独立 Skill。

## 核心任务

**不是把历史知识搬进赏析，而是用外部材料解决一个具体的解释问题。** 外证可以确定词语旧义、校正题署、限定时地、辨明受话者、排除牵强寓意，也可能只能提供一个竞争假说。背景材料与词意相容，并不等于历史事实或作者意图已获证明。

### 触发条件

出现旧名物、方言、异文、缺文、署名争议、写作小序、年代地理、赠答场合、节日活动、官制、社会身份，或有人声称词中某位女子、亡国政治影射、悼亡经历“必定”对应真实人物时调用。局部细读已充分、没有可靠材料、只为增加引书数量时不必调用。

## 默认七步

1. **先问清待判对象**：是哪一句有歧义？究竟查作者、作年、场合、制度、旧义还是寄托？先给出词中可见事实，避免先有传记故事再找词句凑证据。
2. **校文本**：查看题名、词牌、词前小序、不同传本、字词异文、署名。文字不稳定就把两种读法并列。0151:m2 的“未便／来便”、0141:m0 的缺文、0513:m0 的同名公度问题，都证明校勘在某些解释前是必要动作。
3. **列来源及其证据角色**：作者原序／书信／纪行、同代档案和史书、地方志、词话笔记、后世传奇、前人赏析分别放好。判断记录的是谁亲眼见了什么、是谁转述何人、成书何年、是否独立；作者自序内转述捕雁故事仍非作者亲眼目击（1493:m0）。
4. **只恢复必要语境**：根据问题选择年代、官历、地图、交往关系、节令与民俗、官制与社会分工、器物制作、旧词汇或思想框架；事实核验任务交给 HISTORY，本类负责选材与词句连接。把确定事件与由词意猜测的生活经历分开。某项背景可使一种读法合理，却未必唯一。
5. **建立可检查的连接链**：某来源记载 → 原词相应字句 → 它能纠正哪种误解 → 由此可支持多强的文学解释。说明证据发挥的是定时、定位、释物、限定人物，还是提供一种情感解释，不能只给“作者命运坎坷”。
6. **找一个会推翻结论的反例**：传本异文？对象生卒不合？地望或行程不通？当时消息尚未传到？后人传说反向附会？制度背景是否只是类型化知识？同样的词句是否能支持非政治解释？反例成立则收缩或撤回判断。
7. **回到读者的问题作答**：突出真正改变理解的一两项背景，写清“可证／较可能／待考”的等级。无证不编年谱、不指定情人、不以现代价值观代替古人本意。

## 证据分层

- **作品层**：原词、原题、小序及它们的传本状况。原题、序也可能被后人改写；不能假定永远原真。
- **资料层**：史书、年谱、书信、地方志、风俗和工艺材料的确切记述，须核来源年代、独立性与冲突。
- **判断层**：某位赏析者如何把上述资料对应到词意；不将研究者对作者心理、婚恋或政治立场的推断直接改成事实。
- **方法层**：Critic 可以迁移的查证、对读、限定和反证步骤；它是本 Skill 的对象，不应吞并前三层。

没有回查原史籍时，要说“现有方法观察引某书”，不可宣称“已核史书证实”。针对原作者思想或某个同名人物，允许合理地保留未知。

| 写于何时 | chronology-constraint：交叉任职年、亲友生卒、别作纪年，遇冲突先排除 | 0069:m1、0513:m0、1508:m0；词意相似不能精确定年 |

| 名家为什么这样解释 | interpretation-genealogy：把词评旧说与其实际论据分开，再检反读 | 0108:m0、1270:m6；旧评不能直接替作者发言 |

| 文中思想词属于什么历史语义 | intellectual-tradition：辨禅宗、儒学、隐逸、忠节等传统，并核词内用法 | 0010:m0、0853:m3、1329:m6；不把现代政治伦理词汇反投给古人 |

以上是 **18 种可并用的候选论证动作**，不是强制路由，更不要求每首词把它们全部调用一次。前 707 条首轮编码的主类由规则辅助归纳；110 条代表案例的二轮判读另记于 refinement-review.json，包含 6 项主类纠正建议，主控应以实际证据重新审核。

## 三个反证实验

- **校底本与年代**：0513:m0 中若“公度”被推作黄公度，人物生卒与作者年代不合。排除这个候选以后仍应写“真实公度待考”，而不是马上宣布另一位人选正确。
- **剥离后见之明**：0969:m0 记作者营建带湖早于后来落职。若解释把后来罢官当他写作时已知道的原因，时间方向便错。0812:m0 还须分事件发生和死讯实际抵达两件事。
- **身份归属和政治象征**：1177:m3 从绮窗、熏炉等器物推女主人公身份，最多支持一定生活条件；1150:m4 用同时政局读伍子胥，可成候选政治阐释，却不足以认定词专为岳飞伸冤。

## 回答形式

可用短链写成：“本词明确写……；某材料记……，因而……字更可能指……；这种证据排除……，但并不能确认……。” 只引用必要片段，不用背景小论文代替细读。

**架构分工**：本 Skill 教方法；Library 保留外部文献和版本锚点；Notebook 存具体作品判断及其修订史；Persona 不自动继承现代赏析者的审美或历史伦理立场。候选研究稿不等于 Skill 已上线或提高模型表现。
