# ALLEGORY｜寄托、象征与比兴分析

> Critic 日常默认调用版；研究草稿，未上线。依据《唐宋词鉴赏辞典》1505 篇赏析统一数据中的 **228 条 ALLEGORY 记录**（原始 ID 见 allegory-source.jsonl）。原记录有短引、段落、字符坐标和段落哈希；本轮完成结构化观察的逐条再归纳，**没有重新通读全部原赏析，也不能由此保证评论者的寄托解释成立**。

## 职责与交接（边界协作修订）


- **主责**：检查从字面人事物象到潜在寄托的解释桥梁及证据强度。
- **何时作为主方法**：明确询问政治、身世、比兴、象征或字面之外的可能指涉时。
- **不负责**：把花鸟风雨逐一对应官员，或以词人身世自动覆盖字面爱情和景物。
- **需要协作时**：词面物象交 IMAGE 或 TEXT_WORD；作者身世和政治事实交 HISTORY／CONTEXT；具体审美效果可交 AESTHETICS；存在竞争解释时可由 DEBATE 对证。
- **交接前的证据**：输出字面读法、对应桥梁、竞争读法和所缺外证；隐含寄托不是谜底。
- **易错边界**：“西风”可以制造阻隔感，不自动等于秦桧或元廷；“落花”也不必然代表亡国。

以最能解决用户当前疑问的一类为主，只有辅助分析能提供新证据或完成不同的推理动作时才加一类；原始分类标签不代表必须加载一个独立 Skill。

## 一、这项方法解决什么

解释作品如何借景物、人物、历史旧事或典故，让情感与判断在词面以外产生第二层乃至多层意义。

关键不是找到某个固定「象征物→所指」的词典，而是**复原从文本现象到解释的桥梁**：

- 花与人怎样在姿态、命运、声口上发生对应？
- 由春残、雨急、失群孤雁推及时代与士人处境时，使用了哪些材料？
- 一条寓意能解释多少独特细节？为它牺牲了多少词面事实？
- 这是词人明确安排的表达、评论者的归纳，还是后代读者可以合理生出的历史共鸣？

不得因某个读法高远、政治意味强，就自动置于实景或爱情之上。

## 二、默认的分析流程

1. **恢复词面**。注明作品、版本、词中说话者、明写的人物与景物、时间变化、叙述条件。先用短句交代作品字面怎样读得通。引用评论时明确这是谁的判断。
2. **找触发点**。圈出能支持二级解读的确切东西：双关字、拟人动词、花与人物的同构细节、跨句反复、知名典故、词题或小序。没有触发点，先不要谈象征。
3. **说明转换关系**。写出「A 的哪项属性 → B 的哪项处境/情绪」。避免仅写「某物象征政治」；应指出共同的动作、结果、受阻方式或价值关系。
4. **安排证据顺序**。词中明确语句优先，其次为同篇映照与确切典故；前代传统和作者别篇帮助形成候选；具体政治身份、系年、创作动机另须可靠史料。仅有后代评语时，注明归属于该评论者。
5. **运行竞争性解释**。比较单纯咏景/闺情、一般人生感悟、身世自况、家国寄托等；各读法分别解释了哪些细节，留下哪些问题。若多种解释兼容，允许并存。
6. **检查过拟合与反证**。若必须把花、风、雨、燕逐一配成忠臣、权奸、亡国、降臣，这套隐喻的独立支撑在哪里？替换成别的历史人物是否一样通？有没有一个词句与模型相反？
7. **写有限结论**。分别报告可见的修辞动作、合理的候选寓意、评论者特有主张及尚不能确定的历史所指。不能以联想代替史实证明。

## 三、按问题选分析动作

| 问题或触发 | 优先方法 | 要得到的东西 |
|---|---|---|
| 咏柳咏梅似在写人 | 物人映射、人格投射 | 形态/动作/命运的具体对应，何处不对应 |
| 把花鸟山月写得有情 | 移情与拟人 | 谁把自己的情绪赋给了物 |
| 一词可兼实景、人物、典语 | 双关词眼、词面寓意双存 | 两种读法的语言依据和增量 |
| 香草美人、梅竹岁寒等 | 检查比兴传统 | 前文本的语义资源及本篇改动 |
| 词中借屈原、范蠡、昭君等 | 历史典型迁移 | 原故事哪种关系与本篇对应 |
| 词人、咏物角色可能同命 | 角色自况、物性人格化 | 处境相似点，以及真实作者的证据距离 |
| 从离别、闺情推国事 | 私情—共同命运扩展 | 从哪句词/地理/史事发生升级 |
| 多物象被各配政治角色 | 连续映射一致性审计 | 逐项独立证据、反例及是否猜谜 |
| 评论用「似」「可能」 | 悬置、反附会 | 不同可读方案和不确定性归属 |

这些方法可交叉，**不是每次都要做一遍**。无明显第二层触发时，停留在细读、叙事或艺术形象分析即可。

## 四、典型论证与证据等级

**较清楚的局部物人比兴：0289:m0。** 张先咏柳，评论者把柳枝的细腰、叶眉和柳丝愁肠分别连向女子姿态与思绪。先辨这些具体对应，才谈咏柳与写人如何共存。它比「柳象征某女子」更可操作，但不能据此确定真实女子身份。

**词面不被政治寄托取代：0456:m4、0813:m4。** 岷峨山景、天气阴晴可以带出思乡、仕路变迁；佛教淡泊与对现实的不满也可能共居。这类分析的成功不在于全部翻译成政治，而在于两层如何互相照亮，并保留现场景物及情绪的作用。

**历史材料只能提高可能性：0313:m4、0643:m2。** 评论者将晏殊男女离别联到庆历新政人物去朝，或把周邦彦春回雁翔、涂香争妍读成新党人员进退。可把它们当政治背景实验，然而**没有同期证据时，不能把映射升级为创作事实**。一旦每个花鸟都有特定党派身份，首先测试是不是过度索隐。

**评论者主动设停止线：0984:m3、1018:m4、1371:m6、1389:m4。** 辛弃疾青山江水一词虽可含寄托，评论明言难一一指实；周济的「北都旧恨／南渡新恨」可以是后世读者理解；龙涎及宋陵联想即便可能，也不应逐句索证；亡国诗意与花鸟逐个分派历史人物必须区分。这些不是「象征失败」，反而是**寄托解释如何自我约束**的示范。

**作品情境与评论者心理不能混同：0089:m2、0597:m3。** 神鸦求食与商女依人处境可形成自怜读法，白鹭久立也能被想作知音，但人物是否确曾自怜、鸟是否有意陪伴，都不能由合理的诗性想象冒充事实。

## 五、回答质量要求

对复杂解读优先呈现：

1. **可见文本**：短引、作品位置与描述；
2. **映射动作**：A 的哪个细节通向 B 的哪个意义；
3. **额外材料**：旧典、同篇对应、同作者其他作品或史事的出处；
4. **解释收益**：比字面读法多解释了什么；
5. **反例及保留**：为何尚不能指定具体人物、年代或政治动机；
6. **证据状态**：评论者原有判断／本模型候选／明确有引文支持的修辞动作／待原文或史料校验。

反事实比兴或作者自况不能替代必要的史料检索；论证成熟也不意味着 Critic 已在真实任务中证明性能提升。Skill 是候选方法，不是人格价值立场，不替代 Library、Notebook、Persona。
