# DEBATE｜异说辨析与论证反驳

> Poeticus Critic 日常候选 Skill。来源：634 条 DEBATE 原始方法观察，保留原始 ID、评论者短引和段落/字符/哈希锚点。本轮完成首轮结构化编码，包含重点人工核查与规则辅助分类；**并未重新通读634条相关的现代赏析全文**。以下方法教 Agent 怎样辨析，不预设某位评论者一定正确。

## 职责与交接（边界协作修订）


- **主责**：公平重建现有不同主张并比较其证据、逻辑及结论强弱。
- **何时作为主方法**：存在真实的版本、作者、句义、寄托或审美评价异说时才调用。
- **不负责**：为了辩论编造对手，或驳倒一个理由就宣布相反主张已得证。
- **需要协作时**：字词争点交 TEXT_WORD，史实交 HISTORY，典源交 ALLUSION，声律交 PROSODY，寄托交 ALLEGORY；DEBATE 只负责评估相互竞争的论证。
- **交接前的证据**：逐方列出主张、可核证据、分歧前提和可能改变结论的新材料。
- **易错边界**：反驳“某词必为伪作”的一个证据，不等于就证明该词必为真作。

以最能解决用户当前疑问的一类为主，只有辅助分析能提供新证据或完成不同的推理动作时才加一类；原始分类标签不代表必须加载一个独立 Skill。

## 一、先认出三种不同争论

**事实争论**：谁作的、写于何时、哪种异文更早、某句引文是否真实、该诗是否为词。用可核的传本、史料、年代和音律检验，不能靠审美意见裁定。

**解释争论**：谁在说话、某字如何读、上下片是否连贯、是否存在政治寄托。用文本细节与竞争解释来比较；没有排他证据时可以多解。

**评价争论**：是否高雅、是否淫靡、豪放与婉约何者更好。必须说清双方评价标准；评论者的伦理偏好与作品可见特征不等价。

## 二、通用七步

1. **把争点说准**：列出旧说 A 和新说 B，分别判为事实、解释或审美；原材料没有明确对手便不假造。
2. **按原作者还原意见**：引述批评者的短句、具体依据及出处，避免断章取义和以权威充理由。
3. **拆出推理链**：文本观察、隐含前提、旁证、解释结论分别写清；看哪一环真正被争辩。
4. **寻找决定性材料**：版本年代、句法、上下句、词牌体制、平行词例、真实历史材料。优先找能使两种说法出现不同预期的证据。
5. **找反例与竞争解释**：作品风格可以多样，历史地名可能是文学惯称，闺情不一定藏政事，历史传说可能是因词造事。别把可能性换成确定性。
6. **只修订确实被推翻的部分**：证明 A 某个理由无效，不自动证明 B；接受部分旧说、缩小适用范围或保持悬置都可以。
7. **写出证据状态**：评论者所说、作品原句、模型归纳、待核传本/史料分开。未回查原著则明确标待核。

## 三、按需选择的工作方法

| 争论焦点 | 先做什么 | 特别警告 |
|---|---|---|
| 花落／花露、词题有无、残句补本 | 并列底本，核版本年代、句法、声律 | 艺术更好不等于最早版本 |
| 某词属作者甲还是乙 | 核最早可见署名、传承、写作时代 | 风格像某人并非作者权证明 |
| 某年写、某事触发 | 建事件年表，查本事最早出处 | 因词造事与后见之明 |
| 字义、指代、人物语气 | 重建两套句法及相邻语境 | 译得通不等于排他 |
| 人物身份、梦境、动作次序 | 分别恢复说话者、时空、动作 | 词的留白不可补成史实 |
| 跳接、重复或无章 | 寻意象、语气、时序的潜在线索 | 跳接也可能真有缺陷 |
| 真旷达、伪消极、反语 | 对照字面与后续实际情绪动作 | 复杂情绪可以并存 |
| 春花、君臣和故国寄托 | 从词面到旁证逐层增证 | 不能逐物分派政治人物 |
| 豪放、婉约、清空、实密 | 以单篇反例修正作者类型 | 反例推翻「总是」，不推翻主要倾向 |
| 名家声誉、雅俗、思想高下 | 说明双方具体价值尺度 | 审美与道德事实分开 |
| 咏物忌直接题字等通则 | 找真反例并修订适用条件 | 反驳绝对规则不意味反过来绝对化 |
| 两种都能解释的结尾 | 保留各说成立前提和共同事实 | 没有排他证据应承认多义 |

## 四、代表案例及可迁移推理

**文学史通则：0001:m2。** 从成熟形式推出李白不可能作某词，暗含「艺术类型不能提前成熟」的普遍命题。找到有效先熟例子可以反驳通则，**但不自动证实李白作者权**。

**章法争议：0002:m2、0026:m1。** 有人将相隔的春柳、秋原或短句跳接判成散乱；评者尝试寻找暗中的情绪与叙事流转。应先具体说明连接在哪些字句上发生，不能以「潜气内转」四字替代证明。

**异文和署名：0032:m2、0326:m0、0912:m0、1163:m3。** 异文「花落／花露」需同时比较底本与意境。作者归属要核最早记载与不同选本的继承关系。《钗头凤》早期资料仅存两句而晚本有全篇，不能混作同样强的作者权证据。后人补出的十四字，必须保持可疑。

**理论反例：0382:m1。** 章质夫咏柳花词直接提到题字却未必浅露，说明「咏物绝不可露题」应修订为因具体写法而定的条件规则。

**历史不可能与解释仍可存在：0630:m4。** 仲殊生活在南渡前，因此南渡后某事不可能是他写词当时的实事；但「繁华终会消散」并不依赖具体那次事件，仍可保留。

**反对伪作推理：0853:m2。** 贺兰山与黄龙府方位未必吻合现实抗金地理，却可能沿用边塞文学词汇。这仅削弱地理证伪，不证明作者必为岳飞。

**审美尺度：0852:m0、1120:m4。** 以高昂胜低沉、清晰胜朦胧作为唯一评价标准都有反例。应区分艺术策略与道德/政治评价，并在词句层面判断效果。

**政治索隐：0053:m0、1135:m0、1404:m3。** 将男女爱情一律译为君国之情，或花鸟逐一指定权臣，是一套需要独立证据的强假说。读者可能感到亡国哀思，但并不因此取得作者原意的确证。

**来源错误：0651:m4、0913:m0。** 引文今本无证或驿壁故事混入别篇诗句时，先退出该证据链；不要凭动人的故事延续原定说法。

## 五、输出纪律

默认用紧凑自然语言讲清：双方争哪一事实或解释、各据什么、何项证据真正有区别、是否出现反证、可作何种程度的结论。若只能证明旧评不足，可写「此说尚不足为据」，不必刻意另立唯一新说。

讨论具体考据前，先取可靠 Library 原典或工具证据；DEBATE 的论证结构不能替代 HISTORY、ALLUSION、TEXT_WORD 或 INTERTEXT 的实际资料。该 Skill 是方法候选，不是 Critic 固定立场。
